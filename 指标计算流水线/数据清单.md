# 数据清单：指标 → 输入 → 输出 映射

本表是**离线流水线**中各指标的"输入表/列 → 计算逻辑 → 输出列/文件"的逐项溯源。
（与之前独立产出的《指标数据字典》同源，区别在于：此处所有输入均为本目录 `data/` 内已落地的本地文件。）

---

## L1 背景特征层

### 1. mgr_total_tenure_v2（经理任职天数）
- **公式**：`(report_date − 经理任职起始日).days`
- **输入表**：`data/L1_背景特征层/基金经理任职信息.csv`（宽表，基金代码是列名，单元格为"基金概况串"）
- **取值逻辑**：正则 `(\d{4}-\d{2}-\d{2})\s*~` 从单元格取首个日期为任职起始；一只基金多位经理 → 取**任职最早（最资深）**者。
- **输出列**：`mgr_total_tenure_v2` → `output/L1_背景特征.csv`

### 2. log_fund_age（ln 成立年数）
- **公式**：`ln((report_date − 成立日).days / 30.44 / 12)`
- **输入表**：`data/L1_背景特征层/基金详细信息_最终版.csv`（列 `inception_date` 或 `成立日期`）
- **输出列**：`log_fund_age` → `output/L1_背景特征.csv`

### 3. 控制变量 gender / education / CFA / school
- **逻辑**：取基金"任职最久"经理的个人特征。
- **输入表**：`基金经理任职信息.csv`（经理→基金映射） + `基金经理信息_最终版.csv`（`school/education/gender/CFA`）
- **输出列**：`gender, education, CFA, school` → `output/L1_背景特征.csv`（按 fund_code 铺满该基金所有季度）

## L2 持仓偏离层

### 4. AS_improved（主动份额）
- **公式**：`½ Σ |w_fund − w_bench|`，基准 = 沪深300(真实权重) + 中证500(等权) 合并后归一（Σ=1）
- **输入表**：
  - `data/L2_持仓偏离层/基金持仓明细_全量修正版.csv`（`fund_code, report_date, stock_code, hold_ratio%`）
  - `data/L2_持仓偏离层/沪深300成分股权重_真实.csv`（`stock_code, bench_weight`）
  - `data/基金基础信息/中证500成分股.csv`（`stock_code, weight`）
- **输出列**：`AS_improved` → `output/L2_持仓偏离.csv`

### 5. ICI / ICI_raw（行业集中度偏差）
- **公式**：`Σ (w_fund,ind − w_mkt,ind)²`；`w_mkt,ind` 取各行业**横截面平均权重**（市场代理）
- **推荐口径（ICI = 归一化版本）**：权重先归一化到 Σ=1 再算，消除基金股票仓位高低对偏离的机械干扰。
- **数据来源（已升级，2026-08-12）**：`data/L2_持仓偏离层/行业集中度HHI_申万31.csv`
  —— 由用户经 AKShare `index_component_sw` 下载的 **stock_code→申万一级映射（股票行业映射.csv，5203只，覆盖99.2%）**，
  对 `基金持仓明细_全量修正版.csv`（股票级 hold_ratio）**按股票聚到申万31** 后计算。含 4 个口径，本流水线取：
  - `ICI` ← `ICI_normalized`（归一化，面板均值≈0.262，n≈9407）
  - `ICI_raw` ← `ICI`（原始 NAV 权重，面板均值≈0.124，n≈9407）
- **日期对齐**：成品文件仅含 (fund_code, year, quarter)，用持仓文件 (fund_code,year,quarter)→report_date(+1天) 还原，仅保留落在骨架内的观测（4279 个，覆盖≈44.7%）。
- **与旧口径差异**：旧 `_norm_industry()`（82混标→申万31等权拆分，均值0.014）已废弃；新口径基于股票级真实持仓，行业偏离平方和量级约 0.26（SW31 更细→偏离更大，0.262 属合理；较原面板 0.071 偏大，因分类更细、偏离更充分表达）。
- **输出列**：`ICI, ICI_raw` → `output/L2_持仓偏离.csv`

### 6. industry_hhi / industry_hhi_raw（行业赫芬达尔）
- **公式**：`Σ w_ind²`
- **推荐口径（industry_hhi = 归一化版本）**：权重归一化到 Σ=1（标准 HHI 口径，消除现金占比干扰）。
- **数据来源（已升级，2026-08-12）**：同条目 5 的 `行业集中度HHI_申万31.csv`，取：
  - `industry_hhi` ← `hhi_normalized`（归一化，面板均值≈0.083，n≈9407）
  - `industry_hhi_raw` ← `industry_hhi`（原始 NAV 权重，面板均值≈0.031，n≈9407）
- **说明**：归一化 HHI 反映行业权重平方和（Σw²，权重归一化到 Σ=1），量级约 0.08（31 行业分散分布下合理）；SW31 31 行业比原面板更细→单行业占比更小→HHI 更低。原始 NAV 权重 HHI（Σw<1）机械性偏低（约 0.03），仅作并列复核。
  原始 NAV 权重 HHI（Σw<1）机械性偏低，仅作并列复核。
- **旧口径废弃**：`SW31_MAP` + `_norm_industry()`（82混标等权→0.053）不再使用，保留为 deprecated 注释。
- **输出列**：`industry_hhi, industry_hhi_raw` → `output/L2_持仓偏离.csv`

## L3 交易执行层

### 7. SDI（风格漂移）
- **公式**：滚动 OLS(基金季收益 ~ 4 风格指数) 后，**相邻权重向量曼哈顿距离**；窗口 = 8（2026-08-12 由 12 改为 8，暖机期缩短、跨度延长至≈4.3年、覆盖 66.6%）
- **输入表**：
  - `data/L4_风险应对层/基金净值历史_全量.csv`（算基金季收益）
  - `data/L2_持仓偏离层/风格指数季度收益.csv`（4 风格：列 `399373/4/6/7_q_return`）
- **输出列**：`SDI` → `output/L3_交易执行.csv`

### 8. TO_two_sided（双边换手率，含卖出侧，**唯一主变量**）
- **公式**：`(total_buy + total_sell) / (2 × avg_aum)` —— 标准双边换手率
- **输入表**：`data/L3_交易行为层/基金换手率_双边_含卖出.csv`
  （原项目 `数据/无用数据/基金换手率_计算值.csv`，**曾被误归为"无用数据"**；
  该文件含 `total_buy / total_sell / avg_aum / turnover_rate`，且
  `turnover_rate == (total_buy+total_sell)/(2×avg_aum)` 经验证最大误差≈0）
- **覆盖**：200 只基金、2021H1–2025H1（半年频 9 个快照，report_date +1 天对齐），约骨架 18%（200/400 基金；因半年频，观测占比更低）——待 CSMAR/Wind 补齐全部 400 只（见 `数据下载提示词_2026-08-13.md` P1）。
- **为何弃单边**：原 `TO_calc`（仅买入侧、缺卖出）已**于 2026-08-12 移除**，不再作为主变量。
- **OCI_two_sided**（换手率离差）：`(TO_two_sided − 基金内均值) / 基金内标准差`，与 TO_two_sided 一一对应。
- **辅助列**：`total_buy, total_sell, avg_aum`（原始买卖总额与平均净资产，透明可追溯）
- **输出列**：`TO_two_sided, OCI_two_sided, total_buy, total_sell, avg_aum` → `output/L3_交易执行.csv`

## L4 风险应对层

### 10. ARG（主动风险增益）
- **公式**：`Σ_t |RG_t|`；`RG_t = R_fund,t − Σ w_i·R_i,t`；季度内 3 个月 RG 绝对值之和
- **输入表**：
  - `data/L4_风险应对层/基金净值历史_全量.csv`（基金月收益）
  - `data/L2_持仓偏离层/基金持仓明细_全量修正版.csv`（持仓权重快照，按最近 ≤ 月 的快照匹配）
  - `data/股价行情/个股月收益率_全量.csv`（约 4185 只个股月收益，权重按可用股票重新归一）
- **输出列**：`ARG` → `output/L4_风险应对.csv`

### 11. return_volatility（收益波动率）
- **公式**：季度收益滚动 8 期标准差（`min_periods=3`）
- **输入表**：`data/L4_风险应对层/基金季度收益.csv`（`fund_code, report_date, quarter_return`）
- **输出列**：`return_volatility` → `output/L4_风险应对.csv`

## L5 认知偏差层

### 12. de（处置效应 = PGR − PLR）
- **公式**：`PGR − PLR`（Odean 1998 快照法）；仅 6/12 月全持仓快照参与
- **输入表**：
  - `data/L2_持仓偏离层/基金持仓明细_全量修正版.csv`（持仓快照）
  - `data/股价行情/个股月收益率_全量.csv`（区间收益，用于判定卖/持股票的盈亏）
- **辅助列**：`pgr, plr, gains_sold, gains_held, losses_sold, losses_held`
- **输出列**：`de, pgr, plr` → `output/L5_认知偏差.csv`（非 6/12 季度为 NaN）

### 13. lsv（交易趋同度 / 共识偏离度，LSV 1992 口径）
- **公式（标准 LSV 1992）**：`|p_i − p̄_t| − AF`，`AF = sqrt(2/π)·sqrt(p̄_t·(1−p̄_t)/n_i)`（二项式调整因子）
- **口径说明（2026-08-12 对齐教科书）**：本仓库无真实逐笔买卖方向，用**持仓快照增减方向**作买卖代理——
  对每只股票在相邻两次持仓快照间，统计全市场「增持基金数 B / 减持基金数 S」，
  采用 LSV1992 教科书**买入占比** `p_i = B/(B+S) ∈ [0,1]`（净买入该股票的基金占比）；
  `p̄_t = 期内各股票 p_i 的横截面均值`（市场整体净买入倾向基准）；
  股票层 `H_i = |p_i − p̄_t| − AF`，基金层 lsv = 对其交易过的股票取 `H_i` 均值。
  （此前代码误用带符号净比 (B−S)/(B+S)，已于 2026-08-12 改为买入占比；代码/文稿/教科书三者一致。）
- **输入表**：`data/L2_持仓偏离层/基金持仓明细_全量修正版.csv`（持仓快照 → 增减方向）
- **数量级**：重建后 lsv 均值≈0.089、范围 [−0.068, 0.276]、约 0.2% 为负，量级贴合经典 LSV 文献
  （Wermers 约 0.02–0.07）；与原面板 lsv（均值≈−0.23，基于真实买卖方向）数据源不同，仅作可计算代理。
- **输出列**：`lsv` → `output/L5_认知偏差.csv`

### 14. risk_asym（风险不对称，**逐期滚动时变量**）
- **公式**：滚动窗口=8（min_periods=4）逐期：`窗口内盈利期(>0)收益标准差 − 亏损期(≤0)收益标准差`（2026-08-12 由基金级常量改为时变；原常量在基金固定效应下面变异为 0 无法识别）
- **文献依据**：杠杆效应（leverage effect, Black 1976 / Christie 1982 / Bekaert & Wu 2000）
- **输入表**：`data/L4_风险应对层/基金季度收益.csv`
- **辅助列**：`n_gain, n_loss`（该窗口内盈利/亏损期数）
- **输出列**：`risk_asym` → `output/L5_认知偏差.csv`（同一基金各季度取值不同，覆盖 73.7%）

## 数据一致性核对与整合（2026-08-13）

### 背景：双副本目录的口径风险
项目存在两份原始数据副本：
- **权威工作副本**：`指标计算流水线/data/`（lib_metrics 实际读取来源，`D(layer,file)` 解析到这里）
- **归档镜像**：`数据/`（早期大盘点产物，含大量原始日志/报告，574 个文件仅存于此处）

二者共享 20 个同名数据文件。**今日全量 MD5 比对发现 3 处静默分歧**，已全部对齐：

| 文件 | 分歧实质 | 权威版 | 处理 |
|---|---|---|---|
| `L2_持仓偏离层/基金持仓明细_全量修正版_v2.csv` | 归档版 660,611 行含 **232,038 个重复主键**（fund,date,stock），且 `stock_code` 带 6 位前导零（`000979`）；工作版 428,571 行已去重、`stock_code` 去零（`1979`） | **工作版**（去零格式与 `个股月收益率_全量.csv` 一致，RG/ARG/LSV 连接键才正确） | 归档版 ← 工作版（覆盖掉会破坏连接的旧格式） |
| `L2_持仓偏离层/股票行业映射.csv` | 工作版 **5 字节（空）**，归档版 201KB（stock_code→申万31 全量映射） | **归档版**（完整） | 工作版 ← 归档版（补齐，当前 lib_metrics 仅注释引用、未实际消费，留作后续备用） |
| `FF因子/FF因子_合并完整版.csv` | 工作版止于 **2026Q1**（97 行），归档版为超集止于 **2026Q3**（99 行，0 冲突） | **归档版**（更新） | 工作版 ← 归档版（pull 入 2026Q2/2026Q3 因子）→ 重跑 06/99 → `excess_return`/ff3-5 α 覆盖延伸至 2026Q2，与 `quarter_return` 时间跨度对齐 |

### 关键约定（务必牢记，防止再次分歧）
1. **`stock_code` 去前导零约定**：`基金持仓明细_全量修正版_v2.csv` 与 `个股月收益率_全量.csv` 均使用**去零字符串**（`1979`=001979、`1`=000001）。二者必须同格式，否则 RG/ARG/LSV 连接失效（覆盖骤降为 0）。任何重新导出持仓/收益文件时，**不要补回前导零**。
2. **权威源单一化**：`指标计算流水线/data/` 为唯一权威输入；`数据/` 应仅作镜像。重跑流水线前先确认两处同名文件 MD5 一致（已用 `_backup_pre_sync_20260813/` 留存被覆盖前的旧版以备回滚）。
3. **持仓 v2 已去重**：主键 (fund_code, report_date, stock_code) 唯一；归档旧版 232k 重复行为冗余脏数据，覆盖无害。
