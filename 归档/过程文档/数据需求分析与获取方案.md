## 一、数据需求总览

### 1.1 按层级分类

| 层级 | 指标 | 所需数据 | 数据频率 | AKShare可获取 | Wind/CSMAR |
|------|------|----------|----------|:---:|:---:|
| **L1** | Experience(从业年限) | 基金经理任职起止日期 | 更新时 | ✓ fund_manager_em | ✓ |
| **L1** | RPI(排名压力指数) | 基金业绩排名 | 季度 | △ 需自行计算 | ✓ |
| **L2** | AS(Active Share) | 基金全持仓 + 基准成分股权重 | 半年度 | **△ 仅前十大** | ✓ 全持仓 |
| **L2** | ICI(行业集中度) | 基金行业配置 + 市场行业权重 | 半年度 | ✓ fund_portfolio_industry | ✓ |
| **L3** | RG(Return Gap) | 基金月度净值 + 季度持仓 + 个股月度收益 | 月度 | ✓ 已验证 | ✓ |
| **L3** | ARG(绝对收益缺口) | 同RG | 月度 | ✓ 已验证 | ✓ |
| **L4** | SDI(风格漂移指数) | 基金日/月净值 + 4类风格指数收益 | 月度 | ✓ stock_zh_a_hist | ✓ |
| **L4** | 波动率管理 | 基金日度净值 | 日度 | ✓ fund_open_fund_info_em | ✓ |
| **L5** | OCI(过度自信指数) | 基金换手率 | 半年度 | △ 需计算 | ✓ 直接提供 |
| **L5** | PS(可预测性分数) | L1-L4全指标 + 持仓变动方向 | 季度 | ✓ 已有数据 | ✓ |
| **控制** | 基金规模/费用率/年龄 | 基金基本信息 | 年度 | ✓ fund_individual_basic_info_xq | ✓ |
| **被解释** | 超额收益 | 基金月度收益 + Fama-French因子 | 月度 | ✓ 净值可算 | ✓ |

### 2.3 真实数据计算结果验证

**Active Share**（基于前十大重仓股，等权基准近似）：
- 5只基金×20季度 = 100个观测
- AS均值 = 0.7600，标准差 = 0.1141
- 文献参考：Cremers & Petajisto (2009)美国样本AS均值 ~0.70
- **注意**：前十大重仓股计算的AS偏高，因为未持仓的90%+组合权重被视为完全偏离基准。精确AS需要半年报全持仓数据。

**Return Gap**（月度频率）：
- 5只基金×57个月 = 285个观测
- RG均值范围：0.11% ~ 1.19%（月度）
- 季度ARG范围：0.04 ~ 0.54
- 文献参考：Kacperczyk et al. (2008)月度RG均值 ~0.05%；申宇(2013)ARG中国样本更大
- **注意**：RG偏高可能因为：(1)前十大持仓仅覆盖~60%仓位，剩余40%的"隐形交易"被全部归入RG；(2)港股持仓的收益未计入持仓模拟收益。

## 三、AKShare无法获取的数据及替代方案

### 3.1 基金半年报/年报全持仓（关键缺口）

**影响**：这是计算精确Active Share的核心数据。AKShare仅提供前十大重仓股，导致：
- AS系统性偏高（未覆盖部分被视为完全偏离基准）
- 无法准确计算ICI（行业集中度依赖完整持仓）

**获取方案**：

| 方案 | 来源 | 成本 | 操作方式 |
|------|------|------|----------|
| **方案A（推荐）** | Wind终端 | 需Wind账号 | 基金 → 定期报告 → 持仓明细 → 导出Excel |
| **方案B** | CSMAR数据库 | 需学校账号 | 基金研究 → 基金持仓文件 → 下载CSV |
| **方案C** | 巨潮资讯网 | 免费 | 手动下载基金半年报/年报PDF → 解析持仓表 |
| **方案D** | 东方财富Choice | 需Choice账号 | 基金 → 持仓明细 → 全部持仓 |

**方案C操作步骤**（免费）：
1. 访问 http://www.cninfo.com.cn/new/disclosure/stock?orgId=jjpl&stockId=
2. 搜索基金代码 → 选择"定期报告"
3. 下载半年报/年报PDF
4. 用Python pdfplumber库解析持仓表格
5. 半年报通常在8月底发布（截止6月30日），年报在3月底发布（截止12月31日）

### 3.2 指数成分股精确权重

**影响**：AKShare仅提供成分股列表，不提供精确权重。等权近似会导致AS计算偏差。

**获取方案**：

| 方案 | 来源 | 成本 | 说明 |
|------|------|------|------|
| **方案A** | 中证指数公司官网 | 免费 | https://www.csindex.com.cn/ → 下载中心 → 成份股权重 |
| **方案B** | Wind终端 | 需账号 | 指数 → 成分股 → 权重 → 导出 |
| **方案C** | 近似：用市值加权 | 免费 | 用个股总市值/总市值之和作为权重 |

### 3.3 基金费用率

**影响**：控制变量之一，也需从RG中扣除费用影响。

**获取方案**：
- AKShare fund_individual_basic_info_xq 可获取当前费用率
- 历史费用率变动需从基金年报中提取
- 或直接使用0.015（1.5%）作为偏股混合型基金的典型费率

### 3.4 Fama-French因子数据

**影响**：计算超额收益（被解释变量）需要FF3/4/5因子。

**获取方案**：

| 方案 | 来源 | 说明 |
|------|------|------|
| **方案A** | CSMAR因子库 | 学校账号直接下载月度因子 |
| **方案B** | RESSET数据库 | 类似CSMAR |
| **方案C** | 自行计算 | 用AKShare下载全市场个股数据，按FF方法构造 |
| **方案D** | Python库factor_analyzer | 内置FF3因子（可能滞后） |

## 四、大规模数据下载方案

### 4.1 200只基金完整下载

已验证的脚本 `download_real_data.py` 支持批量下载，修改 fund_codes 列表即可：

```python
# 从基金列表中筛选200只符合条件的基金
fund_list = pd.read_csv('数据/fund_list.csv')
# 筛选: 偏股混合型, 成立满5年, 规模>2亿
# 需要从fund_basic_info中获取成立日期和规模进行筛选
```

**预估时间**：
- 200只基金 × 5年 × (净值1秒 + 持仓5×0.5秒 + 行业5×0.5秒 + 基本信息0.3秒) ≈ 2小时
- 个股月度收益: ~500只独立股票 × 0.2秒 ≈ 2分钟
- 总计约 **2-3小时**

**限速策略**：
- AKShare基于东方财富/天天基金网，高频请求可能被限流
- 每次请求间隔0.3-0.5秒
- 如遇限流，增加间隔至1秒或更换IP

### 4.2 推荐的样本筛选条件

```python
# 200只偏股混合型基金筛选标准
筛选条件:
  - 基金类型: 混合型-偏股
  - 成立时间: <= 2019-12-31 (成立满5年)
  - 最新规模: >= 2亿元
  - 存续状态: 未清盘、未转型
  - 排除: QDII、FOF、指数型
```

## 五、数据缺口对研究的影响评估

| 数据缺口 | 影响程度 | 影响指标 | 应对策略 |
|----------|---------|----------|----------|
| 全持仓缺失 | **高** | AS精确值 | 用前十大近似 + 敏感性分析 |
| 成分股权重缺失 | 中 | AS精确值 | 用市值加权近似 |
| 费用率历史 | 低 | 控制变量 | 用0.015固定值 |
| FF因子 | 中 | 超额收益 | 自行计算或用CSMAR |

### 前十大重仓股近似AS的可行性评估

**可行**：
- 前十大通常覆盖50-70%的基金净值
- AS的横截面排序在近似和精确值之间高度相关（Cremers 2009原文验证）
- 分组检验（五分位）的结论不受近似影响

**局限**：
- AS绝对值偏高，不能直接与文献的0.70比较
- 需在论文中说明使用前十大近似的限制
- 稳健性检验中应报告全持仓子样本的AS作为对照
