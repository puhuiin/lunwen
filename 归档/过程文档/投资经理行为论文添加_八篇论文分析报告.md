## 论文2：传染的资金——基于网络结构的基金资金流量及业绩影响研究

|------|------|
| **标题** | 传染的资金：基于网络结构的基金资金流量及业绩影响研究 |
| **作者** | 刘京军、苏楚林 |
| **期刊** | 《管理世界》 |
| **年份** | 2016年第1期 |
| **研究层级** | **L3 交易行为**（资金流量传染与网络结构） |
| **核心方法** | 空间计量模型（Spatial Panel Model）；基于基金重仓持股数据构建动态变化的基金网络矩阵（持股相似性矩阵）；最大似然估计法（Elhorst 2014方法）；零成本组合交易策略 |
| **数据来源** | **WIND数据库**（开放式基金数据，2005年1月-2014年12月，股票型与偏股型主动管理基金）；**CSMAR数据库**（基金净值数据） |
| **核心发现** | (1) 基于基金重仓持股网络，基金之间的资金流量具有显著的溢出效应（传染性），处于网络结构中的基金资金流量存在正的相互影响。(2) 基金网络带来的资金流量与基金的超额收益率显著正相关。(3) 基于网络结构的零成本组合交易策略年超额收益率达到6%。(4) 基于重仓持股的网络结构促进了机构行为的一致性，有助于理解机构羊群行为、拥挤交易以及股市崩盘行为。 |
| **关联度** | **高**。该文从网络结构视角研究基金资金流量的传染效应，与基金经理行为分析中"交易行为的传染与模仿"高度相关。可在研究基金行为一致性、羊群效应、资金流量与业绩关系时引用。引用方式：刘京军、苏楚林（2016）基于基金重仓持股网络发现，基金之间的资金流量具有显著的传染效应…… |

## 论文3：基金未公开的信息——隐形交易与投资业绩

| 字段 | 内容 |
|------|------|
| **标题** | 基金未公开的信息：隐形交易与投资业绩 |
| **作者** | 申宇、赵静梅、何欣 |
| **期刊** | 《管理世界》 |
| **年份** | 2013年第8期 |
| **研究层级** | **L3 交易行为**（隐形交易/主动投资行为）+ **L5 认知行为**（职业忧虑、薪酬激励动机） |
| **核心方法** | 修正Kacperczyk et al.（2008）的收益缺口指标（取绝对值后加总，解决正负抵消问题），构建ARG隐形交易指标；Carhart（1997）四因子模型风险调整；面板数据固定效应两阶段工具变量法处理内生性；横截面回归分析隐形交易的决定因素 |
| **数据来源** | **RESSET（锐思）基金数据库**（基金净值、分红、拆分除权因子、除权数据、基金管理人薪酬数据、基金年报和半年报持股明细数据），样本区间2005年1月-2010年12月，328只基金、8662个观测值 |
| **核心发现** | (1) 隐形交易与基金的超额收益率显著正相关，隐形交易最多的基金组合年超额收益率较最低组合高出6%。(2) 基金经理的职业忧虑与隐形交易显著负相关（历史业绩越差，隐形交易越高）；基金资金流动、薪酬激励对提高隐形交易有明显的促进作用。(3) 隐形交易与基金的私有信息显著正相关，基金经理获取更多私有信息提高了隐形交易程度，从而获得更高超额收益率，一定程度上回答了"Fama悖论"。(4) 研究表明我国资本市场处于弱式有效市场状态，资产私有信息尚未完全反映到价格中。 |
| **关联度** | **高**。该文直接研究基金经理未公开的隐形交易行为及其对业绩的影响，涉及职业忧虑、薪酬激励等行为动机，与"基金经理交易行为"研究的多个层面高度契合。可作为L3交易行为（隐形交易）和L5认知行为（行为动机）的核心文献引用。引用方式：申宇、赵静梅、何欣（2013）修正了隐形交易衡量指标，发现隐形交易与基金超额收益率显著正相关…… |

## 论文6：校友关系网络、基金投资业绩与"小圈子"效应

| 字段 | 内容 |
|------|------|
| **标题** | 校友关系网络、基金投资业绩与"小圈子"效应 |
| **作者** | 申宇、赵静梅、何欣 |
| **期刊** | 《经济学（季刊）》 |
| **年份** | 2015年10月，第15卷第1期 |
| **研究层级** | **L1 背景特征**（校友关系网络）+ **L3 交易行为**（隐形交易、主动投资）+ **L5 认知行为**（社会关系与信息传递） |
| **核心方法** | 复杂网络中心度理论（Freeman 1979）：程度中心度（Degree，衡量直接校友关系广度）、中介中心度（Between，衡量间接校友关系）、亲疏中心度（Close，衡量关系深度）；Carhart（1997）四因子模型风险调整；手工整理校友关系信息；R软件igraph包计算网络中心度 |
| **数据来源** | **RESSET（锐思）数据库**（上市公司高管信息和基金经理信息子数据库中的简历数据；基金单位净值、复权因子数据、投资组合明细数据），手工整理沪深股市2005-2013年上市公司高管和基金经理的教育背景信息，189只基金、6617个观测值 |
| **核心发现** | (1) 校友关系的广度和深度都能为基金带来业绩的正向提升：关系广度最高的基金组合每年超额收益率比最低组合高出11.37%；关系深度最高的组合比最低组合高出9.12%。(2) 校友关系存在"小圈子"效应，只有直接校友关系和亲密的校友关系能够影响基金业绩，间接校友关系对基金业绩的影响未能被证实。(3) 校友关系网络对基金业绩正向影响的作用机制在于：关系网络能够享有更多的私有信息，从而进行更加积极的主动投资与隐形交易。(4) 校友关系网络在股票买入时能够产生显著的正向影响，但卖出时不显著，说明"有福同享，大难临头各自飞"。 |
| **关联度** | **高**。该文从基金经理的社会关系网络（校友关系）背景特征出发，研究其对投资业绩和交易行为的影响，直接涉及L1背景特征和L3交易行为两个层面。与"基金经理行为分析"研究高度契合，是研究基金经理社会网络、背景特征对投资行为影响的标志性文献。引用方式：申宇、赵静梅、何欣（2015）发现校友关系网络的广度和深度均能显著提升基金业绩，存在"小圈子"效应…… |
