模块B：BHS锦标赛压力 — 具体计算步骤

1
确定排序期和测试期：按BHS原文，将每年分为两半：
排序期 = 1-6月（前半年） | 测试期 = 7-12月（后半年）
2
计算排序期累积收益率 CR：
CR_i = Π_{t=1}^{6}(1 + R_{i,t}) - 1
其中 R_{i,t} 为基金 i 在第 t 月的月度收益率
3
同类基金排名分组：在同类型基金（如全部股票型基金）内部按CR排名
前50% → 赢家（Winner, Dummy=0） | 后50% → 输家（Loser, Dummy=1）
4
计算排序期和测试期的风险（标准差）：
σ_rank = std(R_{i,t}), t ∈ [1月, 6月] （排序期风险） σ_test = std(R_{i,t}), t ∈ [7月, 12月] （测试期风险）
5
计算风险调整比率 RAR：
RAR_i = σ_{test} / σ_{rank}
RAR > 1 → 下半年增险 | RAR < 1 → 下半年降险 | RAR = 1 → 风险不变
6
检验锦标赛效应：
H₀: E[RAR | Loser] ≤ E[RAR | Winner] 回归模型: RAR_i = α + β · LoserDummy_i + γ · Controls_i + ε_i
β > 0 且显著 → 输家增险 → 锦标赛效应存在
BHS原文 vs 我们的改进：原文用334只美国基金(1976-1991)，手动收集Lipper数据。我们用AKShare API自动化获取400+只中国基金，覆盖率100%，且可自由扩展样本量。

1.0阶段完整代码框架

import akshare as ak import pandas as pd import numpy as np from datetime import datetime # ========== Step 1: 获取基金净值 ========== fund_list = ak.fund_name_em() # 筛选股票型+混合型，成立≥2年 stock_funds = fund_list[fund_list['基金类型'].str.contains('股票型|混合型')] all_nav = {} for code in stock_funds['基金代码'][:400]: try: nav = ak.fund_open_fund_info_em(symbol=code, indicator="累计净值") nav['月度收益率'] = nav['累计净值'].pct_change() all_nav[code] = nav except: continue # ========== Step 2: 计算CR (排序期累积收益) ========== def calc_cr(monthly_returns_h1): """排序期1-6月累积收益率""" cr = 1.0 for r in monthly_returns_h1: cr *= (1 + r) return cr - 1 # ========== Step 3: 计算σ_rank 和 σ_test ========== def calc_rar(monthly_h1, monthly_h2): """RAR = σ_下半年 / σ_上半年""" sigma_rank = np.std(monthly_h1, ddof=1) sigma_test = np.std(monthly_h2, ddof=1) if sigma_rank == 0: return np.nan return sigma_test / sigma_rank # ========== Step 4: 同类排名分组 ========== # 在同类型基金内按CR排名 # 后50% → Loser=1, 前50% → Loser=0 df['Loser'] = (df['CR'].rank(pct=True) < 0.5).astype(int) # ========== Step 5: OLS回归 ========== import statsmodels.api as sm X = sm.add_constant(df[['Loser', 'Exp', 'log_AUM']]) model = sm.OLS(df['RAR'], X).fit() print(model.summary()) # β(Loser) > 0 且 p < 0.05 → 锦标赛效应验证

四、与BHS原文的关键对比

对比维度BHS原文 (1996)我们的实现
样本334只美国基金400+只中国基金
数据来源Lipper/CDA（手动收集）AKShare API（自动化）
时间跨度1976-1991（15年）2015-2024（约10年）
排名基准同类基金CR排名同（股票型/混合型内排名）
分组方式中位数划分赢家/输家同
检验方法列联表 + 非参数检验OLS面板回归 + 固定效应
控制变量基金规模、类型+ 经理特征(Exp/Gender/Edu)
市场环境美国成熟市场中国新兴市场（锦标赛效应预期更强）
注意事项：
  • 防未来函数：排序期CR必须在测试期开始前已知，不能用全年数据
  • 样本筛选：需排除ETF/LOF（被动管理），排除成立不足2年的基金
  • 同类排名：必须按基金类型分组排名，不能跨类型比较
  • 新发基金：任职不足半年的经理排除，避免数据不完整
  • 多经理基金：需决定取主经理还是取平均
