一

学术不端风险审查

ACADEMIC MISCONDUCT RISK

本章节从抄袭剽窃、数据造假、选择性报告、p值操纵四个维度，系统评估研究过程中可能存在的学术不端风险。

1.1 抄袭 / 剽窃风险

抄袭剽窃风险
中低风险

指标来源　AS (Cremers 2009)、RG (Kacperczyk 2008)、ICI (Kacperczyk 2005)、SDI (寇宗来 2020)、OCI (Odean 1998) 均为前人提出的经典指标。

风险评估　中低风险。指标计算方法本身属于公共知识，关键在于应用场景（中国市场）和组合方式（五层框架）。

合规措施　每个指标明确标注原始文献，计算方法在论文中详细说明来源。

1.2 数据造假风险

数据造假风险
中风险

风险点1　AS指标 62% 观测值相同 (0.8325)，标准差仅 0.041（美股样本为 0.17）。

风险点2　存在两套回归结果（R²=0.024 vs R²=0.068），数据不一致。

风险评估　中风险。AS问题源于数据源限制（用前十大重仓近似全持仓），非故意造假，但需在论文中明确说明。

合规措施　在"数据局限"章节声明 AS 计算方法限制，报告所有数据来源。

需重点关注

AS 指标 62% 观测值相同的问题若不在论文中说明，一旦被审稿人发现将直接质疑数据质量与结论可信度，属 P0 级改进事项。

1.3 选择性报告风险

选择性报告风险
低风险

风险点　仅报告显著结果，可能隐瞒不显著结果。

风险评估　低风险。当前报告了 ICI 和 SDI 的不显著结果，安慰剂检验中 ICI/SDI 未通过也如实报告。

合规措施　完整报告所有指标结果（显著/不显著），报告安慰剂检验失败案例。

1.4 p值操纵风险

p值操纵风险
中风险

风险点　多次检验（5个行为指标 × 多个模型）可能增加假阳性。

风险评估　中风险。5个指标 × 4个模型 = 20次检验，未做多重检验校正。

合规措施　建议加入 Bonferroni 校正或 FDR 控制；报告所有检验结果而非仅显著的。

2.2 堆砌风险评估

问题识别

8个核心指标全部来自前人文献，计算方法均为直接引用，未做实质性改进。

堆砌风险
中高

严重程度　中高。如果仅是"指标搬运 + 中国数据验证"，学术贡献有限。

改进建议

  1. 至少对 2-3 个指标提出改进（如 AS 用基金合同基准、OCI 用 NLP 文本分析）。
  2. 五层框架的组合方式本身是创新，需在论文中突出。
  3. 牛熊市异质性发现是原创贡献，需深入分析机制。

2.3 理论框架原创性

五层递进框架

将分散的行为指标纳入"L1 → L2 → L3 → L4 → L5"递进结构，这是本文的理论组织创新。

级联式综合判断

区别于晨星的并列打分和华泰的 PCA 聚类，采用因果递进 + 分布分类的方式。

评估结论

框架组织有新意，但各层内部指标计算方法缺乏创新，原创性主要体现在"组织方式"而非"指标本身"。

三

创新点识别与强化

INNOVATION IDENTIFICATION & STRENGTHENING

3.1 已有创新点

  1. 五层递进框架（理论创新）：首次将 BHS 锦标赛、AS 持仓偏离、RG 隐形交易、SDI 风格漂移、OCI 认知偏差纳入统一递进框架。
  2. 中国市场 AS 负向发现（实证创新）：AS 与业绩负相关（t = -3.80***），与美股正向发现相反，揭示了 A 股市场特性。
  3. 牛熊市异质性（实证创新）：AS/SDI/OCI 在牛熊市符号翻转，行为指标在牛市预测力更强（R² = 0.171 vs 0.063）。
  4. OCI 最强预测力（实证创新）：OCI 是 A 股基金业绩最强预测指标（t = -26.02***），在美国市场文献中未见同等强度的发现。
  5. 级联式综合判断方法（方法创新）：因果递进 + 分布分类 + 回归验证三步法。

3.2 需强化的创新点

创新点 当前状态 改进 / 升级方案
AS 计算改进 用前十大重仓近似全持仓，导致 AS 变异度不足 用基金合同基准替代等权基准
OCI 定义改进 用换手率 Z-score，争议较大 加入 NLP 文本分析衡量过度自信
PS 模型升级 简化为 Logistic 回归 用 LSTM 深度学习模型
因果识别 仅有相关性分析 用 IV / DID / RDD 进行因果推断

3.3 创新点强度评级

创新点 类型 强度 评价
五层递进框架 理论 中 组织方式新，但各层指标均为现成
AS 负向发现 实证 中高 与美股相反，有市场特异性价值
牛熊市异质性 实证 中高 符号翻转是有趣发现，需机制解释
OCI 最强预测 实证 高 t = -26.02 极强，美国文献未见
级联式判断 方法 中 区别于现有方法，但实现尚简
核心亮点

OCI 最强预测力（t = -26.02***）是本项目最具发表潜力的发现，建议作为论文的核心卖点重点包装，并补充机制解释与稳健性检验。

四

研究规范性改进建议

IMPROVEMENT RECOMMENDATIONS

4.1 必须改进（P0）

P0 级 — 投稿前必须完成
  1. AS 变异度问题必须在论文中说明，否则被审稿人发现会质疑数据质量。
  2. 多重检验校正必须加入，20 次检验不做校正会被质疑。
  3. 两套回归结果的不一致必须解释清楚。

4.2 建议改进（P1）

P1 级 — 强烈建议完成
  1. 因果识别至少做 IV（经理变更作为工具变量）。
  2. 退市基金幸存者偏差需在"研究局限"声明。
  3. 指标计算改进至少完成 AS 和 OCI 两项。
  4. Fama-MacBeth 回归需改善（当前仅 12 期成功）。

4.3 可选改进（P2）

P2 级 — 提升论文质量的可选方向
  1. NLP 文本分析增强 OCI 定义。
  2. LSTM 模型构建 PS。
  3. 中美市场对比分析。
  4. DID 因果识别（2015 股灾 / 2020 疫情作为外生冲击）。
