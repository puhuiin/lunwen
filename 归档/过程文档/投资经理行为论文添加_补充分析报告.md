### 1. 参与成本、基金业绩与投资者选择

| 字段 | 内容 |
|------|------|
| **标题** | 参与成本、基金业绩与投资者选择 |
| **作者** | 冯旭南、李心愉 |
| **期刊** | 《管理世界》 |
| **年份** | 2013年第4期 |
| **研究方法** | 面板数据回归（固定效应模型），以基金公司特征作为信息搜集成本（参与成本）的代理变量 |
| **数据来源** | 2005—2012年开放式股票型基金，国泰安（CSMAR）中国开放式基金研究数据库 |
| **核心发现** | ① 中国基金投资者追逐绩优基金而抛弃绩劣基金（与美国市场"凸性"不同，中国绩劣基金遭受赎回压力）；② 参与成本对资金流量—业绩敏感性有重要影响，大公司家族、明星家族或媒体关注度高的基金在业绩排名高时资金流量更敏感，排名差时敏感性降低；③ 早期"赎回异象"结论主要受股权分置改革前特殊市场环境影响 |
| **L1-L5关联** | **高 — L4/L5**。业绩—资金流量关系（PFR）构成基金经理的隐性激励机制（锦标赛效应，L4）；历史业绩对未来资金流量的预测能力（L5）。参与成本视角丰富了投资者行为对基金管理人激励机制的理解 |

### 2. 基金业绩与投资者的选择——中国开放式基金赎回异常现象的研究

| 字段 | 内容 |
|------|------|
| **标题** | 基金业绩与投资者的选择——中国开放式基金赎回异常现象的研究 |
| **作者** | 陆蓉、陈百助、徐龙炳、谢新厚 |
| **期刊** | 《经济研究》 |
| **年份** | 2007年第6期 |
| **研究方法** | 面板数据分析（14只偏股型开放式基金），业绩—资金流动关系（PFR）检验 |
| **数据来源** | 2003年4月至2006年9月，14只偏股型开放式基金 |
| **核心发现** | ① 中国开放式基金业绩与资金流动呈负相关且为凹形（与成熟市场相反），即"赎回异象"——业绩好的基金面临更大赎回压力；② 投资者选择未能发挥"优胜劣汰"机制，表现为"反向选择"；③ 影响赎回的因素还包括收益稳定性、分红、基金规模等；④ 赎回压力迫使基金管理者改变稳定投资策略，被迫变现盈利资产 |
| **L1-L5关联** | **高 — L4**。"赎回异象"反映投资者认知偏差与处置效应（L4），并对基金经理产生扭曲的隐性激励（锦标赛效应反向化），迫使基金经理调整交易策略（L3关联） |

### 3. 基金业绩与资金流量：我国基金市场存在"赎回异象"吗？

| 字段 | 内容 |
|------|------|
| **标题** | 基金业绩与资金流量：我国基金市场存在"赎回异象"吗？ |
| **作者** | 肖峻、石劲 |
| **期刊** | 《经济科学》 |
| **年份** | 2011年第1期 |
| **研究方法** | 固定效应非平衡面板数据回归，分段线性回归（piecewise linear regression），虚变量回归；采用原始回报率、市场模型及Fama-French三因子模型调整后回报率作为业绩度量 |
| **数据来源** | 2005—2012年股票方向开放式基金，国泰安数据库（CSMAR），要求至少24个月历史净值 |
| **核心发现** | ① 以基金中长期（年度）回报率为解释变量，发现滞后年度回报率对资金净流量产生显著正面影响，投资者总体"追逐业绩"而非"反向选择"，"赎回异象"是假象；② 与海外不同，我国明星基金不能获得超额资金流入，投资者不热衷"追星"；③ 早期"赎回异象"结论源于使用短期季度回报率和平衡面板数据的方法论缺陷；④ 运用"委托—代理"理论分析业绩激励机制 |
| **L1-L5关联** | **高 — L4/L5**。直接检验业绩—资金流量关系作为基金管理人隐性激励的有效性（L4锦标赛效应）；业绩对未来资金流量的预测能力（L5）。方法论上强调中长期业绩指标和风险调整后回报的重要性 |

### 4. 基金业绩与资金流量：明星效应与垫底效应

| 字段 | 内容 |
|------|------|
| **标题** | 基金业绩与资金流量：明星效应与垫底效应 |
| **作者** | 杨坤、曹晖、宋双杰 |
| **期刊** | 《管理科学学报》 |
| **年份** | 2013年5月（第16卷第5期） |
| **研究方法** | 部分线性半参数回归方法估计PFR曲线，并在此基础上模拟计算检验基金经理投资的风险偏好 |
| **数据来源** | 2005—2010年季度基金数据，342支股票型和偏股混合型基金，国泰安数据库（CSMAR） |
| **核心发现** | ① 不支持"赎回异象"假说，发现中国市场存在明显的"明星效应"和"垫底效应"——PFR曲线随业绩提高呈上升趋势，形态为两头陡峭中间平缓；② 基金经理中期业绩较好时倾向于承担风险以成为"明星基金"，中期业绩较差时通过承担风险以摆脱"垫底"；③ 业绩居中的基金风险偏好随中期业绩平缓上升 |
| **L1-L5关联** | **高 — L4**。直接检验基金经理风险偏好与中期业绩的关系（锦标赛效应/risk-shifting behavior，L4）。在委托代理框架下揭示了PFR非线性形态对基金经理风险承担行为的激励效应 |

### 5. 基金业绩对投资者申购、赎回行为的影响：考虑股市表现的证据

| 字段 | 内容 |
|------|------|
| **标题** | 基金业绩对投资者申购、赎回行为的影响：考虑股市表现的证据 |
| **作者** | 肖继辉 |
| **期刊** | 《经济与管理研究》 |
| **年份** | 2016年第4期 |
| **研究方法** | 面板数据回归，将投资者行为区分为申购行为和赎回行为，引入业绩与股市表现的交叉变量区分"牛""熊"市 |
| **数据来源** | 2005—2014年偏股型开放式基金 |
| **核心发现** | ① 基金申购量和赎回量均与基金业绩显著正相关；② "赎回异象"在整体上不存在，基金业绩与净流入正相关；③ 不同股市周期投资者行为存在显著差异——"牛市"倾向于"追逐业绩"，"熊市"倾向于"忽略业绩"；④ 用前景理论和处置效应解释：盈利时风险厌恶（兑现收益赎回），亏损时风险偏好（继续持有） |
| **L1-L5关联** | **高 — L4**。投资者处置效应与认知偏差（L4）；牛熊市周期对基金管理人激励机制的非对称影响（L4锦标赛效应）。区分申购与赎回行为揭示了"赎回异象"的信息损失问题 |

### 6. 开放式基金的"赎回困惑"现象研究

|------|------|
| **标题** | 开放式基金的"赎回困惑"现象研究 |
| **作者** | 刘志远、姚颐 |
| **期刊** | 《证券市场导报》 |
| **年份** | 2005年2月号 |
| **研究方法** | 合并数据（pooling）回归方法，截面模型与面板模型双重检验 |
| **数据来源** | 2003年1月至2004年9月，55只开放式基金（31只股票型、16只债券型、8只平衡型），天相数据库 |

### 8. 股市周期与基金投资者的选择

| 字段 | 内容 |
|------|------|
| **标题** | 股市周期与基金投资者的选择 |
| **作者** | 肖峻 |
| **期刊** | 《经济学（季刊）》 |
| **年份** | 2013年7月（第12卷第4期） |
| **研究方法** | 静态和动态面板数据回归，创新性设计交叉变量区分"牛""熊"市基金投资者的业绩敏感性，并对回归系数差异进行显著性检验 |

### 9. 解析我国封闭式基金折价之谜

| 字段 | 内容 |
|------|------|
| **标题** | 解析我国封闭式基金折价之谜 |
| **作者** | 张俊喜、张华 |
| **期刊** | 《金融研究》 |
| **年份** | 约2002年 |
| **研究方法** | 定量分析，横截面回归与时间序列回归，间接检验投资者情绪假说 |
| **数据来源** | 我国封闭式基金 |
| **核心发现** | ① 传统基本面理论（代理成本、资产流动性、基金业绩、资本利得税）无法解释我国基金折价之谜；② 行为金融学"投资者情绪"理论有较强解释力；③ 三大发现：不同基金折价变动高度正相关；新基金选择在折价小时上市；基金折价变动与小市值股票收益率正相关、与大市值股票收益率负相关（第三点与美国相反）；④ 散户是基金主要投资者，情绪波动直接影响折价 |
| **L1-L5关联** | **中 — L4**。投资者情绪作为认知偏差（L4）影响基金定价。虽然研究对象为封闭式基金而非基金经理行为，但投资者情绪理论对理解基金市场行为偏差具有方法论参考价值 |

### 5.2 与L1-L5框架的关联分析

本次补充分析的18篇论文中：

- **高关联度（8篇）**：均围绕中国开放式基金"业绩—资金流量关系"（PFR）展开，核心争论焦点是"赎回异象"是否存在。这些论文与 **L4（认知偏差/风险应对/锦标赛效应）** 高度相关——PFR 构成基金经理的隐性激励机制，"赎回异象"若存在则意味着激励扭曲。其中"明星效应与垫底效应"一文直接检验了基金经理基于中期业绩的风险偏好变化（锦标赛效应/risk-shifting），与L4核心议题最为契合。部分论文同时涉及 **L5（可预测性）**——历史业绩对未来资金流量的预测能力。

- **中关联度（3篇）**：投资者情绪理论（封闭式基金折价）、机构投资者行为对市场波动的影响、利益输送概念（委托代理问题），在理论层面与基金经理行为研究有方法论参考价值。

- **低关联度（7篇）**：属于公司财务、银行治理、宏观经济学领域，与基金经理行为研究无直接关联。

### 5.3 "赎回异象"学术争论脉络

本次分析揭示了国内学术界关于"赎回异象"的重要争论脉络：

| 阶段 | 代表论文 | 核心观点 |
|------|----------|----------|
| 早期发现（2004-2007） | 李曜于进杰(2004)、刘志远姚颐(2005)、陆蓉等(2007) | 中国基金市场存在"赎回异象"——业绩越好赎回越多，PFR呈负相关 |
| 方法论反思（2011-2016） | 肖峻石劲(2011)、杨坤等(2013)、肖继辉(2016)、冯旭南(2013) | "赎回异象"是假象，源于使用短期季度回报率和平衡面板数据的方法论缺陷；使用中长期年度回报率和非平衡面板后发现PFR为正相关 |
| 深化研究（2013） | 肖峻(2013) | 引入股市周期维度，发现牛熊市投资者行为不对称——牛市追逐业绩、熊市忽视业绩 |

这一争论对基金经理行为研究的启示：PFR 作为隐性激励机制的有效性取决于业绩度量方式、市场周期和投资者理性程度，直接影响基金经理的锦标赛效应与风险承担行为（L4）。
