# 《基金经理行为异质性、投资偏离与业绩操纵研究》原始数据字典与使用说明

本目录收录了论文全量实证分析与行为指标构建所需的**全部权威原始数据集**（均为规范的 UTF-8 CSV 纯文本数据，解压后体积约 110 MB，压缩后仅约 25 MB）。
任何学者、审稿人或研究人员均可直接打开、检索、校验这些底层原始数据，并可通过上级目录的 `01_数据获取与指标计算/` 或 `02_实证回归与论文图表/` 实现从原始明细到论文图表的 100% 独立离线复现。

## 二、各层数据集字段字典与详细规范

### 1. `L1_背景特征层/`

#### (1) `基金经理信息_最终版.csv`
- **样本体量**：3,543 行（涵盖全市场偏股型公募基金经理完整名录）。
- **关键字段**：
  | 字段名 | 类型 | 说明 | 示例 |
  |---|---|---|---|
  | `manager_id` | str | 基金经理唯一标识编码 | M001024 |
  | `manager_name`| str | 基金经理姓名 | 张清华 |
  | `gender` | int | 性别虚拟变量（1=男，0=女） | 1 |
  | `education` | str/int | 学历等级（硕士/博士/本科，衍生虚拟变量 `education_level`） | 硕士 |
  | `school` | str | 毕业院校名称 | 清华大学 |
  | `school_tier` | int | 院校声誉虚拟变量（1=985/常春藤/QS前100，0=其他） | 1 |
  | `has_cfa` | int | 是否持有 CFA 资格证书（1=是，0=否） | 1 |
  | `total_exp_days`| float | 行业累计任职总天数 | 3820 |

#### (2) `基金经理任职信息.csv`
- **数据结构**：宽表矩阵（行=经理 `manager_id`，列=6位基金代码 `fund_code`）。
- **单元格格式**：`[基金全称] | [任职区间] | [任职天数] | [任职回报]`
  - 示例：`华夏行业精选混合 | 2018-03-12 ~ 2024-05-18 | 2259天 | 68.42%`
- **用途**：流水线通过正则表达式动态抽取 `start_date` 与 `end_date`，精确匹配每个报告期各基金的实际主在任基金经理，并计算经理累计任职年限 `mgr_total_tenure_v2`。

#### (3) `基金规模历史_批量.csv`
- **覆盖区间**：2006Q1 – 2026Q2，全量季度报告期。
- **关键字段**：
  | 字段名 | 类型 | 说明 |
  |---|---|---|
  | `fund_code` | int/str | 6 位基金代码 |
  | `report_date` | date | 净值报告期（YYYY-MM-DD） |
  | `net_asset` | float | 季度末基金净资产规模（亿元） |
  | `total_shares`| float | 基金总份额（亿份） |

---

### 2. `L2_持仓偏离层/`

#### (1) `基金持仓明细_全量修正版_v3.csv`
- **数据体量**：322,000+ 行，经过严格去重、港股代码清洗与权重校验。
- **关键字段**：
  | 字段名 | 类型 | 说明 |
  |---|---|---|
  | `fund_code` | int/str | 6位基金代码 |
  | `report_date` | date | 持仓报告披露期（季末/半年末/年末） |
  | `stock_code` | str | 6位股票标准化代码（如 `600519`） |
  | `stock_name` | str | 股票简称 |
  | `hold_shares` | float | 持仓股数（股/万股） |
  | `hold_value` | float | 持股市值（元/万元） |
  | `hold_ratio` | float | 持股市值占基金资产净值比例（%） |
  | `rank` | int | 持仓名次（1~10 为前十大重仓，半年报/年报包含全持仓） |

#### (2) `沪深300成分股权重_真实.csv` & `中证500成分股.csv`
- **用途**：主动偏离度（Active Share, AS）与隐性交易度（ICI）的标准市场基准。
- **基准合成规则**：以沪深 300 真实权重为核心，并入中证 500 等权，全市场权重重新归一化至 $\sum w_i = 1$。

#### (3) `股票行业映射.csv` 与 `申万一级行业分类.csv`
- **覆盖标的**：5,203 只 A 股标的，映射到 31 个申万一级行业（如食品饮料、电力设备、电子、医药生物等），用于计算行业集中度 HHI 与行业漂移度 ISDI。

---

### 3. `L3_交易行为层/`

#### (1) `基金换手率_双边_含卖出.csv`
- **口径声明**：严格遵循学术公认的**真·双边换手率（Two-Sided Turnover Rate, TO）**：
  $$\text{TO}_{i,t} = \frac{\text{买入股票总额}_{i,t} + \text{卖出股票总额}_{i,t}}{2 \times \overline{\text{AUM}}_{i,t}}$$
- **字段**：`fund_code`, `report_date`, `total_buy`, `total_sell`, `avg_aum`, `turnover_two_sided`。

#### (2) `基金持仓变动_批量.csv`
- 记录相邻半年度（H1/H2）持仓股票数量变化、买入卖出市值，用于稳健性检验中单边调仓代理变量的交叉检验。

---

### 4. `L4_风险应对层/`

#### (1) `基金净值历史_全量.csv`
- **数据结构**：逐日交易日复权单位净值（Adjusted NAV）。
- **关键字段**：`fund_code`, `trade_date`, `nav`, `adj_nav`, `daily_return`。
- **用途**：计算基金季度实际收益率、下季未来收益率（$Ret_{t+1}$）、年化波动率（`return_volatility`）以及极端市场抗跌指标（ARG）。

#### (2) `基金季度收益.csv`
- 对齐到各季度标准报告期（Q1=03-31, Q2=06-30, Q3=09-30, Q4=12-31）的季度复权净值增长率。

---

### 5. `FF因子/`

- `FF5日度因子.csv` / `FF5月度因子.csv`：
  - 包含市场超额收益（`mkt_rf`）、规模因子（`smb`）、价值因子（`hml`）、盈利能力因子（`rmw`）、投资模式因子（`cma`）以及无风险利率（`rf`）。
- 用于 Carhart 四因子与 Fama-French 五因子时变滚动回归，剥离风险溢价得到真实的季度超额 Alpha（`alpha_q`）。

---

### 6. `股价行情/`

- `个股月收益率_全量.csv`：
  - 包含全市场 A 股月度收益率数据，供处置效应（DE）和羊群行为（LSV）计算股票相对涨跌幅与市场买卖偏离度。

## 三、底层数据如何支撑 25 个微观行为指标

| 维度编号 | 维度名称 | 核心指标代号 | 依赖的底层原始数据文件 |
|---|---|---|---|
| **L1** | 基金经理背景特征 | `mgr_total_tenure_v2`, `log_fund_age`, `gender`, `education_level`, `cfa`, `school_tier` | `L1_背景特征层/` 4个文件 |
| **L2** | 持仓偏离特征 | `AS_improved`, `ICI`, `industry_hhi`, `ISDI`, `style_drift` | `L2_持仓偏离层/` 持仓明细、行业映射、基准权重 |
| **L3** | 交易执行特征 | `TO_two_sided`, `OCI_two_sided`, `SDI`, `trade_intensity` | `L3_交易行为层/` 双边换手率、持仓变动 |
| **L4** | 风险应对特征 | `ARG`, `return_volatility`, `downside_risk`, `mdd` | `L4_风险应对层/` 净值历史、季度收益 |
| **L5** | 认知与行为偏差 | `de` (处置效应), `lsv` (羊群行为), `risk_asym` (风险偏好不对称) | `L2` 持仓明细 + `股价行情/个股月收益率` + `L4` 收益 |
| **定价**| 风险调整收益 | `alpha_q`, `sharpe_ratio`, `future_return` | `L4` 净值历史 + `FF因子/` 五因子数据 |

## 四、数据完整性与合规声明

1. **真实性与可复现性**：本数据集所有原始观测均源自中国基金行业官方信息披露系统、公开交易所交易记录及主流专业金融数据库，未作任何人工合成、捏造或插值篡改。
2. **脱敏与合规**：所有数据均严格按照公开信息披露口径整理，不涉及任何机构未公开内幕信息或非公开交易底稿。
3. **轻量与解耦**：无用缓存、冗余爬虫网页碎片已被彻底清理，保留最为纯粹的结构化 CSV 格式，无需配置 SQL 数据库即可运行。
