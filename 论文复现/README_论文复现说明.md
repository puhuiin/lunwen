# 《基金经理行为异质性、投资偏离与业绩操纵研究》论文全量复现交付包

> **开箱即用声明**：本复现包为论文的**完整自包含交付版本**，内含**全部底层权威原始数据（CSV）**、**25项行为指标重算流水线**、**12张论文三线表与3张高清插图的纯 Python 实证回归脚本**以及**论文定稿文件**。
> 本包已彻底移除所有 bat/sh 脚本与硬编码操作系统特异性依赖，全面原生兼容 **Windows** 与 **macOS (Intel / Apple Silicon) / Linux**。
> 解压后可直接发送给评审专家、合作学者或审稿人，在任意电脑上均能**零网络依赖、零外挂数据库、老老实实逐步复现或纯 Python 一键全流程复现**。

---

## 一、 复现执行方式（两种方式任选）

### 方式一：老老实实逐个模块执行（推荐审稿人与实证检验使用）

各实证回归脚本均位于 `02_实证回归与论文图表/` 目录下。您可以在命令行终端中，按学术逻辑老老实实依次执行：

```bash
# 安装必要学术计算依赖 (只需安装一次)
pip install -r requirements.txt

# 依次执行各步骤实证：
python 02_实证回归与论文图表/step01_表3_逐年描述统计.py
python 02_实证回归与论文图表/step02_表4_表5_单变量与三因变量回归.py
python 02_实证回归与论文图表/step03_表6_六维能力主回归.py
python 02_实证回归与论文图表/step04_表8_AS改进主动份额六道裁决.py
python 02_实证回归与论文图表/step05_表9_表10_表11_群体与典型画像.py
python 02_实证回归与论文图表/step06_表12_样本外6季度长周期盲测.py
python 02_实证回归与论文图表/step07_稳健性_剔除2026Q2极端季检验.py
python 02_实证回归与论文图表/step08_图1_图2_图3_高精度图表生成.py
```
> **终端特性**：每一步脚本执行时，其学术回归表格、样本量、t 统计量、R² 等均会**直接、实时地打印在控制台终端**；在执行 `step08` 时，除了将高清 300 DPI 图片保存至 `figures/` 外，还会**自动弹出论文图1、图2、图3的交互式展示窗口**，方便直接查看图形细节。

### 方式二：全流程 Python 脚本连续执行

如果您希望一口气执行全部实证并查看全量回归流式日志与图表弹窗，可在根目录下直接执行纯 Python 主控脚本：

- **Windows 用户**：
  ```cmd
  python 全流程复现.py
  ```

  ```bash
  python3 全流程复现.py
  ```

主控程序将全自动、端到端依次执行 8 个实证模块，子进程输出**实时流式呈现在终端**，执行至 Step 08 时交互弹出 3 张图表窗口，执行完毕后汇总生成文件清单。

| 步骤 | 对应论文位置 | 核心检验内容与学术产出 | 终端实时展示内容 |
| :---: | :--- | :--- | :--- |

| **Step 02** | **表 4 & 表 5** | 25 项行为指标单变量横截面回归与三种超额收益因变量对照 | 单变量回归系数、t 值、覆盖率及联立回归结果 |
| **Step 03** | **表 6** | 六维综合投资能力主回归模型（单维对照与六维联立净效应检验） | 六维能力单维与联立回归系数、Q5−Q1 收益差 |

## 三、 从底层原始明细重算 25 个指标（指标流水线）

如果您希望从最底层的 32 万行持仓明细、基金经理履历、日频净值历史重新推导和验证指标：

1. 进入 `原始数据/` 目录，直接查看或检索全部底层原始 CSV 文件（详见 `原始数据/README_原始数据说明.md`）。
2. 进入 `01_数据获取与指标计算/` 目录：
   - 核心库 `lib_metrics.py` 会自动探测上级 `原始数据/` 目录，并提供全部 25 个指标的底层向量化计算函数。
   - 依次运行 `01_L1_背景特征.py` ~ `05_L5_认知偏差.py`、`06_因变量.py`，最后运行 `99_合并面板.py`，即可从底层原始明细重新构建出 `output/主分析面板_重建.csv`。

## 五、 环境依赖与平台兼容

推荐 Python 3.9 ~ 3.13。所需的标准学术科学计算库清单：
```
numpy>=1.23.0
pandas>=1.5.0
scipy>=1.9.0
statsmodels>=0.13.0
matplotlib>=3.6.0
```
- **macOS 支持**：制图脚本已内置 `PingFang SC`（苹方）、`Heiti SC` 等原生中文字体支持，在 Mac 环境下绘图绝无方块或乱码。
- **纯 Python 跨平台**：完全抛弃 `.bat` 与 `.sh` 脚本，全平台统一使用标准 `python` 命令调用，审稿与复现过程透明公开。
- **内存与性能**：仅需 4GB 可用内存，全流程实证回归耗时仅约 20 秒。
