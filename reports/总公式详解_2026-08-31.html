三、方程 (6)：六个自变量怎么合成

Scored,i = 1/nd · Σj∈d [ signj · z(Xj,i) ]

一句话：维度 d 的得分 = 该维度内每个成分的（定向 z 分）之和 ÷ 有效成分个数。拆成五个动作：

3.1 成分标准化：z(Xj,i) = (X − x̄) / s

对每个成分，在 362 只基金的横截面上减均值、除标准差——产出"相对同行的排位分"。不是在基金×季度面板上算（那样没有横截面区分度），也不是在全样本期外算（轻微的样本内性由样本外检验兜底）。

为什么必须先 z 再平均：三个比率的量纲天差地别——真实分布里 sharpe 的标准差 0.213、sortino 0.704（是 sharpe 的 3.3 倍）、mppm 0.096。直接加总的话 sortino 会主导合成分，等权变成空话。z 之后三者都在同一把尺子（标准差）上。

3.2 定向：signj 把"方向不同的好"拉到同一方向

有的指标"越大越好"（sign=+1），有的"越小越好"（sign=−1，即 z 取负）。15 个成分的定向全部来自单变量回归的实证方向（方程 6 之前先做了定向回归，15/15 方向一致才准入）：

维度成分（定向）为什么这么定向
基本面优势−任职 −年龄 −规模新经理有职业顾虑更努力[11]；新基金有历史包袱轻；小基金规模不经济[12]
认知能力+risk_asym −de −oc_conf盈利期敢进攻亏损期能防守（下行风险定价[14]）；果断止损好（Odean[3]）；过度自信换手伤业绩[4]

3.3 等权平均：除以 nd = 有效成分个数，缺失不填 0

def ew(frame): return frame.sum(axis=1, skipna=True) / frame.notna().sum(axis=1)

分子跳过缺失、分母只数有值的成分。两个直接后果：①一只"从不亏钱所以没有 Sortino"的基金，其风险转化分 = (z_sharpe + z_mppm)/2 而不是 /3——不因数据可得性被冤枉；②某基金某成分整个样本期都算不出来，该维度用剩余成分合成，仍可进回归。

为什么等权而不是回归定权（论文 F3）：回归权重会被样本期行情牵着走、换窗口即变；等权可复现、不过拟合。稳健性：PCA 权重口径与等权的综合分 Spearman ρ=0.895；按层加权（L4 记 1/5）的排序相关 0.9917——等权不改变任何排序结论。

六、单变量回归：每个成分单独进方程时长什么样

方程 (7) 是六维联立回归。在它之前，论文先做了一遍单变量回归——每个成分单独进方程，验证它自己的方向和预测力（结果即论文表 2）。单变量不是一个方程，而是三种形式，因为成分性质不同。

这一栏就是表 2 的"规格I（横截面）"列。12 个行为成分全部在 5% 水平显著，且方向与计分定向 12/12 一致——这是六维计分能成立的准入条件：任何一个成分方向与定向不符即不准入。

6.2 规格 I·L1 三成分（不含控制变量）

FF5αi = c + β·Xi + ui

L1 三个成分（任职年限、log 基金年龄、log 规模）本身就是控制变量组，让它们自我控制没有意义，所以这三行是裸单变量——表 2 里标注"（单变量）"即指此。结果 t = −1.85 / −4.13 / −1.16：L1 的显著性主要由基金年龄承载，任职年限只有 10% 边际显著、规模本身不显著。这也预告了第七节要讲的事——L1 作为"能力维度"的证据强度天然弱于行为维度。

7.1 只有两个准入成分在面板规格下不显著

oc_conf 过度自信（横截面 −4.11 / 面板 −0.47）与 lsv 交易趋同度（+1.99 / +1.19）。这不是矛盾，而是两套规格在问不同问题的必然结果：

oc_conf 为什么面板会失效——而这恰恰是好消息。横截面比较的是"惯于在盈利后加码的经理"与"不这么做的经理"之间的稳定风格差异；面板比较的是"同一位经理这季比上季更激进了没有"，后者被季度噪声主导。面板系数消失说明过度自信是经理层面的稳定特质，不是逐季波动的择时行为——对一篇"行为画像"论文而言这正是想要的性质：画像刻画的应当是人的稳定倾向，而非一时的操作。
lsv 为什么面板会失效。交易趋同度是横截面构造的静态测度（用全市场基金同期买卖方向算），同一只基金在时序上变化极小，面板回归对它天然缺乏识别信息。横截面 5% 边际显著、面板不显著，是这类指标的典型形态。

7.4 为什么论文正文以规格 I 为准

不是因为规格 I 更显著，而是因为因变量的性质决定了它才是同口径比较。基金层 FF5 alpha 在基金内 100% 是常数（每只基金仅一个取值），把它当逐季变量对季度自变量回归，等于把有效样本从 362 人为放大到近 3,000，t 值会被机械抬高——这是项目早期"显著性多处互相矛盾"的根源，规格 II 改用逐季残差 αi,q 正是为修正此缺陷（详见 scripts/_regress_v3_20260826.py 开头的诊断说明）。因此方程 (7) 用规格 I，规格 II 作为跨期稳健性镜像，论文对它只要求方向一致，不要求同等显著。
