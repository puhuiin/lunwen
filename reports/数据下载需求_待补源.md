## 二、缺口与三类待下载数据（按优先级）

### P0（关键）基金完整持仓历史——补充 2006–2017 区间
- **目的**：现有持仓仅 2018 起，导致 AS / ICI / 行业HHI / DE / LSV 覆盖仅 ~44%、可比期 ~5.5 年；补 2006–2017 可拉平到净值起点，覆盖与稳健性显著提升。
- **来源**：CSMAR（国泰安）基金研究系列「基金持仓明细（全持仓优先，至少重仓股）」或 Wind（万得）基金持仓。
- **字段**：`fund_code`、`stock_code`、报告期（年报/半年报，标注 报告期类型）、持股数量、持股市值(元)、占基金净值比(%)、行业分类(若有)。
- **范围**：本样本 200 只基金 + 尽可能扩至全市场（用于计算市场共识基准 p̄_t）；时间 **2006-01-01 至 2017-12-31**。
- **格式**：CSV，UTF-8；日期 YYYY-MM-DD 或 YYYYQn；`fund_code`/`stock_code` 保留字符串（股票代码不足 6 位左补 0）。

### P1（重要）清盘 / 退市基金清单 + 完整历史净值
- **目的**：现有样本仅含存续基金，存在生存偏差；补清盘基金及其 NAV 可在正文讨论 / 做稳健性。
- **来源**：CSMAR / Wind 基金列表（含 基金状态=清盘/转型/退市、清盘日期）+ 对应日度 / 周度 NAV（2006–2026）。
- **字段**：`fund_code`、基金名称、成立日、清盘日、状态、交易日期、单位净值、累计净值、分红(元)。
- **范围**：与样本同策略（主动偏股）的清盘基金。

### P2（增强）基金逐股买卖方向（交易明细 / 流水）
- **目的**：现有持仓仅有"增减方向"（买卖代理）；若需**严格按 LSV1992 教科书口径**（买入基金占比 p_j）消除代理偏差、且需**真实单边换手率**，需逐股买卖记录。
- **说明**：若仅补 P0（更早持仓），本流水线已可用"持仓增减方向"直接套教科书 buy-ratio `p_j = B/(B+S)`（**无需 P2 即可算标准 LSV**）。P2 主要用于真实换手率与更细的交易行为刻画。
- **来源**：CSMAR / Wind 基金交易明细（`fund_trade_detail`）。
- **字段**：`fund_code`、`stock_code`、交易日期、买卖方向（买 / 卖）、成交数量、成交金额(元)、成交价。
- **范围**：样本 200 只基金，2010-01-01 至 2026-06-30（覆盖现有持仓期即可）。

```
- 基金代码与股票代码均保留为字符串（股票代码不足 6 位左补 0）；
- 日期统一为 YYYY-MM-DD 或 年-季（如 2020Q2）；
- 每张表附字段说明、时间覆盖、样本基金数、缺失/异常标记说明。

- 时间范围：2006-01-01 至 2017-12-31（补充现有 2018 起之前的区间）

- 字段：fund_code, 基金名称, 成立日, 清盘日, 状态, 交易日期, 单位净值, 累计净值, 分红(元)

【3】（可选增强）基金逐股交易明细

- 字段：fund_code, stock_code, 交易日期, 买卖方向, 成交数量, 成交金额(元), 成交价

请返回每张表的字段说明、时间覆盖、样本基金数，以及任何缺失/异常标记的说明。
```
