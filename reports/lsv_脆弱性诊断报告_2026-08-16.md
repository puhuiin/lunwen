## 1. 共线性诊断：lsv 并非被其他变量吸收

- lsv 与全部 RHS 的 Pearson |r| 最大仅 **0.079**（ff5_SMB），Spearman 最大 **0.114**（ICI）。
- lsv 对“其余 RHS”回归的 **R²=0.130 → VIF=1.15，tolerance=0.87**。远低于共线性阈值（VIF<5）。
- **结论**：lsv 的脆弱性**不是共线性**问题——它没有被 TO_wind / SDI / ICI / risk_asym / de 等任一变量吸收。
- 旁注：L2 内部 AS_improved 与 ICI 同属“主动偏离”，天然相关（AS~ICI/hhi 的 R²=0.082），这与 lsv 无关，属 L2 既有发现。

## 3. 机制解读：lsv 不是“失败变量”，而是“被同层强信号掩盖 + 时期依存”

1. **非缩尾/异常值/非线性所致**（B–F 全部 ns，β 稳定 ≈0.015）→ 脆弱性不是数据处理假象。
2. **核心机制 = 被同层兄弟指标（de、risk_asym）掩盖**：规格 J 把 de 与 risk_asym 移出 L5 后，lsv 单独进入模型即显著为正（β=+0.027, t=2.78***）。说明在“L5 三指标同放”的全模型中，de 与 risk_asym（二者本身高度显著）吸收了 lsv 的边际行为信息，使 lsv 的增量贡献被稀释至不显著。这是**块内共线性/信息重叠**，而非与全文其他层（L1–L4）的共线。
3. **时期依存**：规格 G（2022+）lsv 显著为正（t=2.03**），规格 H（2022前）为负但不显著。与 SDI 的有效窗口（2022+，window=8 滚动）一致——**交易执行(L3)与注意力/抱团(L5)的边际信号均在近期 regime 才显现**。早期样本 lsv 几无信息。
4. **规模单调但不足**：AUM 三分位下 lsv β 从小(−0.012)→中(+0.018)→大(+0.027)单调上升，但均不显著，说明大基金抱团溢价略强，仍非稳健信号。

## 4. 对论文/画像的结论与建议

- **重新定性 lsv**：从“不显著的失败指标”升级为“**时期依存 + 被同层强信号(de/RA)掩盖**”的指标。它在近期(2022+)与隔离设定下是显著正 predictor，本质是“基金间抱团/注意力集中度”的横截面分型信号，而非实时因果驱动。
- **画像文档**：已将其从“均显著”降级为“口径依赖/待稳健化”信号（见文档 §6 v4 复核 callout）；本报告机制可进一步支撑该降级——并明确“lsv 的正向信号在 2022+ 与隔离 L5 时复现”。
- **论文稳健性章建议**：将本电池作为 lsv 的专门稳健性附录；强调“L5 三指标同放时 lsv 被 de/RA 掩盖（规格 J），而近期子样本显著（规格 G）”，把弱点转化为方法洞见。
- **诚实披露**：lsv 为 LSV(1992) 标准非负羊群强度代理（基金层均值恒≥0），属“代理口径，待严格复刻”；其时期依存性本身提示中国公募抱团溢价是**结构性的近期现象**，可单列假说待检验。
- **勿过度宣称**：lsv 在全模型 M4 下仍为 ns（t=0.77），论文主表仍以 ns 报告；本报告仅作为其“为何 ns、何时显著”的机制解释，不改变主表结论。
