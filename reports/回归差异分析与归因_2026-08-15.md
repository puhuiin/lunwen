## 一、执行摘要（结论先行）

1. **重跑确定性已验证**：用同一脚本、同一环境（托管 venv，pandas 3.0.5 / statsmodels 0.14.6）重跑，产出的 HONEST 结果与现有 JSON **逐位一致**（β 差异 ≤ 1e-13，属浮点舍入）。你本机手动重跑必得相同结果。
2. **与 2026-08-14 回归的"实质性差异"几乎为零**：H1（SDI）、H3（OCI）、H5（SDI 不含 TO）、H2b（TO_two_sided 稳健性）四个同口径假设的 β 与 t **完全不变**。
3. **唯一可见差异来自"脚本方法学变更"而非"数据更新"**：
   - 新增 **H2 TO_wind**（Wind 集成换手率，N=8463 / 394 只，β=+3.08e-5，t=+3.08***），取代了旧版低覆盖（N=1788）且不显著的 TO_two_sided 主假设；
   - **H4 联合模型**因换手率口径由 TO_two_sided 换成 TO_wind，SDI 与 OCI 的联合系数有微小移动（SDI Δβ=+2.6e-5；OCI 由 −0.00045 变为 +0.00062，但两者本就微小且不显著），**结论方向不变**。
4. **数据演进效应 = 0**：把"面板数据更新"与"脚本变更"分离后，旧面板 + 新脚本的结果与当前结果在所有 6 个假设上 **Δβ < 1e-9**。即 8-15 个股月收益文件的更新**未对 HONEST 回归产生任何影响**。

### 3.3 新增 H2 TO_wind（2026-08-14 不存在）

2026-08-14 版主换手率假设是低覆盖的 TO_two_sided（N=1788，不显著）。本次升级为 Wind 集成换手率 TO_wind（N=8463 / 394 只，β=+3.08e-5，t=+3.08***）。这是**方法学提升带来的新结论**，不是数据变动。

## 四、差异来源分解（三向对照）

为分离"数据更新"与"脚本方法学变更"，本分析在**旧面板（2026-08-14 快照）**上用**当前脚本**重跑得到 `L3_L1_regression_OLD_PANEL_2026-08-15.json`，构成三向对照：

- `R_new` = 新面板 + 新脚本（当前）
- `R_old` = 旧面板 + 新脚本（隔离数据）
- `R_aug14` = 旧面板 + 旧脚本（基准）

| 对比 | 含义 | 结果 |
|---|---|---|
| `R_new` vs `R_aug14` | 数据演进 + 脚本变更 合计 | H1/H3/H5/H2b 不变；H4 微动；新增 H2 |
| `R_new` vs `R_old` | **纯数据演进效应** | 全部 6 假设 Δβ < 1e-9 → **效应为零** |
| `R_old` vs `R_aug14` | **纯脚本方法学变更** | 解释 H4 微动 + 新增 H2 TO_wind |

**结论：所有可观测的回归差异，100% 由脚本方法学变更（引入 TO_wind）解释；数据更新对 HONEST 回归无任何影响。**

## 五、面板变量变动归因（为什么数据更新没影响回归）

以 `(fund_code, report_date)` 为键对齐旧/新基础面板（各 9,974 行），发生变动的列：

| 变动列 | 变动单元数 | 是否进入 HONEST | 说明 |
|---|---|---|---|
| lsv | 9187 | 否 | 个股月收益更新驱动（2026-08-15 更新） |
| ARG | 1089 | 否 | 同上 |
| de | 725 | 否 | 同上 |
| plr | 505 | 否 | 同上 |
| pgr | 360 | 否 | 同上 |
| RG | 269 | 否 | 同上 |
| quarter_return | 1 | 是（DV） | 单点舍入噪声，不在估计样本内 |
| avg_aum | 1 | 是（→log_aum） | 单点，不影响估计 |
| future_return / abs_return | 各 1 | 否 | 单点噪声 |

**关键事实**：HONEST 回归的因变量与自变量仅涉及 `quarter_return`、`SDI`、`TO_wind`、`TO_two_sided`、`OCI_two_sided` 及 6 个控制变量（`log_aum`、`log_fund_age`、`mgr_total_tenure_v2`、`gender_m`、`cfa_d`、`edu_postgrad`）。上述变动列中，**除 DV 的 1 个单点外，其余均非 HONEST 的解释变量**，故无法传导到回归系数。

前期（2026-08-14 复盘）曾记录"lib_metrics.calc_control_vars 经理特征取数口径精炼 → school/education/gender/CFA 发生变动"。本次以严格键对齐复核，**该结论不成立**：

|---|---|---|---|
| school | **0** | 4577 | 4577 |
| gender | **0** | 9794 | 9794 |

即经理背景控制变量在 2026-08-14 快照与当前面板间**逐格一致**。前期"变动"系当时对比对象错位（含 TO_wind 面板与基础面板混比）导致的伪差异。由此，经理控制变量同样对 HONEST 回归无影响，已在上文 Δβ<1e-9 中得到印证。

## 七、结论与建议

1. **可复现性无虞**：本次重跑与历史结果、与手动运行均将完全一致；差异分析本身已用三向对照自证。
2. **唯一需要向论文读者说明的"变更"**：换手率主测度由稀疏的 TO_two_sided 升级为覆盖 86% 的 Wind 集成 TO_wind，带来一个新的显著正关系（H2，β=+3.08e-5，t=+3.08***）。这应作为方法学改进而非"结果漂移"来陈述。
3. **数据更新（个股月收益 8-15 补全）的影响范围**：仅作用于 ARG/de/pgr/plr/lsv/RG 等由个股收益派生的指标，这些指标服务于论文其他模块（如 ARG 主动风险增益、DE 处置效应等），**不影响本文档聚焦的 HONEST 交易行为—业绩回归**。相关模块若引用这些派生指标，需另作一致性核对。
4. **待定稿前确认项（沿用前期提示）**：HONEST 采用同期 DV=`quarter_return`，属"同期联动"而非预测；论文因果措辞与 SDI 同期/时滞对齐仍须在定稿前最终确认。
