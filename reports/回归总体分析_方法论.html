四类行为测度的口径：
  • RA（risk_asym，风险不对称）：前景理论下的风险承担不对称 / 杠杆效应动机。
  • DE（处置效应）= PGR − PLR（Odean 1998 快照法），PGR/PLR 为其两个分量。
  • LSV（羊群 / 交易趋同度）：LSV(1992) 标准口径（代理，因无真实逐股买卖方向）。
  • PGR / PLR：盈利/亏损卖出占比，作为 DE 的分解进入分析。

R1 · 横截面基准回归（基金层）

脚本 09_LSV回归重算 / 12_辅助重算 / 13_分层回归 LSV1992 · Odean1998
① 这是什么回归？
以基金为观测单位（每只基金取指标的时间序列均值），检验三类行为测度对基金同期选股/超额业绩的解释力。相当于论文 §4.2.2 的截面表。
② 为什么要做？
回答「行为偏差是否伴随更高的同期风险调整收益」。横截面口径能最大化样本量（不必等未来季），是后续前向预测的对照基线。

③-c LSV 端到端算例（你点名要的具体公式与数字）

用一只虚构基金 F 演示 LSV 从原始持仓到面板字段（示意数字）：

股票B（增持基金数）S（减持基金数）n=B+Sp_i = B/(B+S)
股票 A3010400.750
股票 B515200.250
股票 C128200.600

第 2 步 市场基准：p̄_t = (0.750+0.250+0.600)/3 = 0.5333。第 3 步 调整因子（股票 A）：AF_A = √(2/π)·√(0.5333×0.4667/40) = 0.7979×0.0789 = 0.0629。第 4 步 单股票趋同度：H_A = |0.750−0.5333|−0.0629 = 0.1538；同理 H_B = 0.1943，H_C = −0.0223（低于随机噪声→≈0）。第 5 步 基金层：若 F 交易了 A、C，则 lsv_F = (0.1538−0.0223)/2 = 0.0658，即落盘到主面板 lsv 的该基金该期值。

AF 为什么存在：即使所有基金独立随机交易，B/(B+S) 也会因抽样噪声偏离 p̄_t；AF 正是「纯随机下的期望偏离」，减去它才得到超出随机的真实趋同——这是 LSV(1992) 的精髓。本仓库用持仓增减方向作代理（无真实逐股买卖），已在论文改称中性「交易趋同度」。
④ 变量位于哪个表的哪个字段？
DV ff5_adj_return / excess_return（均值）来自主面板列（06 计算）； IV risk_asym / lsv / de（基金均值）来自主面板列（05 计算）； 控制 avg_aum（→log_aum）、log_fund_age 来自主面板列（01 计算 / 初始）。
⑤ 初始获取还是计算得出？
全部为计算得出；log_aum 由初始的 net_asset 经 log 变换得到。
⑥ 时间跨度？
基金层均值横跨全样本期 2006–2026，每基金取自身全部可用季度的均值，跨期最长可达约 20 年。
⑦ 足够做回归吗？
充分 当前 N = 362 基金（含/不含 avg_aum 相同，因 avg_aum 已修复）。约束来自 ff5_adj_return 的 362 只与 L5 三测度非空。
⑧ 结果如何判断 / 应达条件？
  • RA 系数应显著为正；DE 系数预期为负或弱；LSV 方向依文献不预设；
  • 控制变量符号符合常识（规模、年龄的系数方向与显著性稳定）；
  • HC1 标准误下 |t|>1.96 视为 5% 显著；R² 量级供参考。
⑨ 能解释什么问题？
行为金融核心命题：基金经理的认知/行为特征是否在同期就被市场定价、转化为可观测的超额收益差异。
⑩ 如何解读参数？
β1 表示 RA 每提高 1 个单位，基金 α 的平均边际变化；因已取基金均值、截面异方差稳健，系数可直接比较相对大小。若「不含 avg_aum」与「含 avg_aum」系数稳定，说明规模不是混淆源。

R2 · 前向预测回归（面板层）

脚本 09 / 10_前向回归核对 / 11 / 13 Grinblatt-Titman1993
① 这是什么回归？
以基金-季度为观测单位，用当期行为测度预测未来超额收益（未来 1 季 fut1q 或未来 4 季均值 fut4q）。
② 为什么要做？
横截面只能看同期关系，前向预测才能回答行为指标是否具备可获利的信息含量，是行为策略有效性的更强证据；并控制年份固定效应隔离宏观周期。
③ 公式
# 面板层，基金聚类稳健标准误，含年份固定效应
fut_k,it = β0 + β1·RA_it + β2·LSV_it + β3·DE_it + β4·log_aum_it
    + β5·log_fund_age_it + Σγ·YearFE + ε_it
# k = 1：fut1q = excess_return 同基金 shift(−1)
# k = 4：fut4q = 未来连续4季 excess_return 的均值

③-b 参数说明表（DV 与回归专属项；RA/LSV/DE/log_aum/log_fund_age 同 R1 表，此处不再重复公式）

变量代表什么具体公式怎么得到单位为何纳入预期

④ 变量位于哪个表的哪个字段？
DV fut1q / fut4q 在脚本内由主面板 excess_return 派生；IV 与 R1 相同；年份 FE 由 year 派生。
⑤ 初始获取还是计算得出？
全部计算得出；fut1q/fut4q 为 excess_return 的时序位移。
⑥ 时间跨度？
面板 2006–2026；「未来季」要求目标季存在，故可预测窗口止于 2026Q1（2026Q2 无下一季，future 为 NaN，已剔除泄漏）。
⑦ 足够做回归吗？
充分 当前 N = 3,224 观测 / 381 基金。基金聚类标准误处理组内自相关。
⑧ 结果如何判断 / 应达条件？
核心看 RA 对未来收益的预测系数；对比 R1 可区分「预测力」还是「同期定价」；年份 FE 吸收宏观；基金聚类下 |t|>1.96 判显著。
⑨ 能解释什么问题？
行为指标是否构成可执行的 alpha 来源——不仅对过去收益有解释力，更能前瞻预测未来表现。
⑩ 如何解读参数？
β1 表示当期 RA 每变动 1 单位，未来 k 季超额收益的平均变动（已控制规模/年龄/年份）。聚类标准误保证推断对基金内序列相关稳健。

R3 · EGARCH 条件不对称稳健性回归

脚本 08_EGARCH条件不对称 / 11 Nelson1991 · Bekaert-Wu2000
① 这是什么回归？
稳健性检验：用 EGARCH(1,1) 从日收益提取条件波动非对称系数 γ（杠杆效应），检验 risk_asym 在控制 γ 后是否仍对未来收益有解释力。
② 为什么要做？
RA 与 γ 可能同源：底层股票的杠杆效应会「机械穿透」到基金收益波动，使 RA 看似是行为构念。若控制 γ 后 RA 仍显著 → 强证据 RA 是独立的行为学构念。
③ 公式
# 单基金 EGARCH(1,1) 提取 γ：
log(σ²_t) = ω + α(|z_{t-1}|−E|z|) + γ·z_{t-1} + β·log(σ²_{t-1})
# γ<0 表示杠杆效应（负冲击更放大波动）

# 面板稳健性回归（对比 M0 / M1）：
future_return_it = β0 + β1·RA_it + [β2·γ_i] + β3·log_aum + β4·log_age + β5·return_vol + ε
# M0 不含 γ；M1 含 γ。γ_i 为基金层 trait，按 fund_code 广播到各季

③-b 参数说明表（R3 专属项；RA/控制同 R1）

⑤ 初始获取还是计算得出？
γ 计算得出（08 对日收益拟合）；其余同前。
⑥ 时间跨度？
γ 覆盖取决于单只基金日收益长度（多数 2020+ 起，需 ≥250 交易日）；future_return 止于 2026Q1。
⑦ 足够做回归吗？
取决于 γ 覆盖 需 RA + future_return + return_volatility + egarch_gamma 同时非空。
⑧ 结果如何判断 / 应达条件？
若 M1 中 RA 系数与 t 值相对 M0 不显著衰减且仍显著 → RA 是独立行为构念；辅助判据：γ 本身均值应为负。
⑨ 能解释什么问题？
为 RA 的构念效度辩护：排除「RA 只是杠杆效应伪装」的质疑。
⑩ 如何解读参数？
β2(γ)：γ 每变动 1 单位对未来收益的影响；β1(RA)：在固定条件杠杆后，行为风险不对称的边际贡献。比较 M0↔M1 的 β1 衰减幅度，即「被杠杆效应吸收的比例」。

R5 · 指标有效性诊断（相关性与 bootstrap）

脚本 12_辅助重算 Kacperczyk2005 · Efron1979
① 这是什么检验？
非因果回归，而是指标构建的内部一致性诊断：(a) 基金层 Pearson 相关 ICI↔HHI、SDI↔ARG；(b) 对 R1 截面 α 回归做 2,000 次 bootstrap，汇报 RA/LSV/DE 的 boot_t 分布与显著占比。
② 为什么要做？
在跑主回归前，先验证自算指标是否「长得像」文献中的同名指标、彼此逻辑关系是否成立，避免用错误构建的指标得出虚假结论。
③ 公式
r_ICI_HHI = corr( ICI_i , industry_hhi_i )  # 预期显著正相关
r_SDI_ARG = corr( SDI_i , ARG_i )  # 风格漂移 vs 主动风险增益
# bootstrap：对基金层样本有放回重抽 B=2000，重估 t 值
boot_t = mean|t|；frac(|t|>1.96)；frac(|t|>2.58)

4 · 论文全部回归清单（按 L1–L5 分层 + 跨层集成 + 稳健性）

用户指出：论文不能只做「行为测度→业绩」的集成回归，L1–L5 每一层自身的变量也应分别检验对基金业绩的影响（如经理个人信息、持仓风格）。本清单重组为三块：① 分层专项回归（每层变量→业绩，已用脚本 13 实跑，每个公式后附参数表）；② 跨层集成基准（R1–R6）；③ 稳健性 / 机制 / 内生性。状态以 2026-08-14 流水线为准。

4.1 设计原则

  • 分层专项（§4.2）：孤立地看「某一层信息能否解释业绩」，避免多层混在一起时效应被掩盖或共线稀释。
  • 跨层集成（§4.3）：把 L1–L5 全部变量同框（R1/R2），检验净效应与相对重要性。
  • 稳健性（§4.5）：因子模型、EGARCH、组合排序、替换因变量等，确认结论非设定依赖。

  • 经济含义需谨慎：RA = σ(盈利期)−σ(亏损期)，高 RA 基金往往收益波动更大；4Q 强正相关可能部分反映「高波动→高风险溢价」而非纯粹选股技能，须控制波动率/用 FF5 调整未来收益进一步拆解。
  • 1Q RA 符号脆弱：单变量 +0.059（t=2.5）加入控制+年份FE 后翻为 −0.32（t=−7）。该翻转提示 1Q 规格受年份FE/多重共线性干扰，不宜作为主结论；建议同时报告含/不含 FE 两版。
