## 一、L1 经理背景层（背景特征）

**指标**：`mgr_total_tenure_v2`（经理任职天数）、`log_fund_age`（基金年龄 ln）、
`gender / education / CFA / school`（经理个人特征，控制变量）。

### 1.1 mgr_total_tenure_v2（已修复口径）
- **问题**：旧实现取「全期最早任职经理」算任期，导致早期季度的 tenure 出现**负值**（起始日 > 报告日，
  约 0.8% 即 79 个观测）——任期不可能为负，是逻辑 bug，且会在回归中污染。
- **修复**：改为取 `report_date` 时刻**在任经理**（`start ≤ report_date ≤ end/至今`）的任职起始日，
  任期 = `report_date − 起始日`（单位天）。**口径即学术标准的「现任经理任期」**，非负。
- **现状**：覆盖 99.7%，均值 ≈1479 天（旧"最长任职"口径 ≈2629 天，差异来自口径选择，非算法错误）。
- **原则遵循**：这是真 bug 修复；口径选择（在任 vs 最长任职）属学术约定差异，已在 README 说明，
  若审稿人要求对齐原面板「最长任职」口径，可改回并把负值截为 NaN。

### 1.2 log_fund_age（无问题）
- `ln((report_date − 成立日) 年数)`，覆盖 100%，无异常。

### 1.3 控制变量 gender/education/CFA/school（曾全空，已修复）
- **问题**：`99_合并面板.py` 合并步骤一度未重跑，导致 `gender/education/CFA/school` **整列全 NaN**。
  另：`基金经理信息_最终版.csv` 含 1 个重复 `manager_id`，级联出 62 行重复观测。
- **修复**：重跑 99 步使控制变量就位（现 9406/9497/9406/4397 非空）；对 info 表去重 +

## 二、L2 投资决策层（持仓偏离）

**指标**：`AS_improved`（主动份额）、`ICI`/`ICI_raw`（行业集中度，构念为相对市场平均的行业偏离，见稿件 §3.3.2）、`industry_hhi`/`industry_hhi_raw`（行业分散度，见稿件 §3.3.3）。

### 2.1 AS_improved（主动份额，无 bug）
- **口径**：`½ Σ |w_fund − w_bench|`；基准 = 沪深300（真实权重）+ 中证500（等权）合并后归一（Σ=1）。
- **问题**：无实现 bug。与原面板排序相关仅 ~0.33，根因是**流水线 raw 持仓数据版本**与原面板所用版本不同
  （属预期差异，非错误）；量级 0.892 vs 0.830 高度接近。
- **保留**：方法标准，无需改。

### 2.2 ICI / industry_hhi（已修复——行业分类严重质量问题，重大）
- **问题（最严重的数据质量问题）**：旧 `基金行业配置_全量.csv` 的「行业类别」列共 **82 个唯一标签**，
  是至少 4–5 套体系混写（证监会 19 门类 / 申万一级 / 中信一级 / GICS 数字码 / 混排），同一真实行业被
  多种命名重复拆分，权重碎片化。`industry_hhi`、`ICI` 直接在这 82 混标上计算 → 与干净申万 31 不可比

- **修复**：用户经 AKShare 下载 `stock_code → 申万一级` 映射（`股票行业映射.csv`，5203 只，覆盖 99.2%），
  对 `基金持仓明细_全量修正版.csv`（**股票级** `hold_ratio`）**按股票聚到申万 31** 重算，
  写入 `行业集中度HHI_申万31.csv`，由 `_load_hhi_merged()` 读取并入面板。
  - **推荐口径取归一化版本**（权重先归一化到 Σ=1，消除基金现金仓位高低对集中度的机械干扰）：

- **现状**：覆盖 44.5%（受持仓明细快照 2018–2025 约束），量级合理，已在论文中诚实说明。
- **保留**：SW31 聚合是标准做法，无需改。

## 三、L3 交易执行层

**指标**：`SDI`（风格漂移）、`TO_two_sided` / `OCI_two_sided`（真双边换手率及其离差）、
透明列 `total_buy / total_sell / avg_aum`。

### 3.1 SDI（风格漂移，已优化窗口）
- **口径**：基金季收益对 4 个风格指数（399373/399374/399376/399377，成长/价值 × 大/小盘）
  做**滚动 OLS**（窗口 8），得风格权重向量（非负截断后归一），相邻两期权重向量的**曼哈顿距离**。
- **问题**：原窗口 = 12，暖机期消耗 12 个季度，使 SDI 首次可用被推到 2023Q3，**有效跨度仅 ~3 年**（覆盖 51.8%）。
  曾设想方案 B「借样本前净值历史拉长」——**核验后不成立**：研究基金在样本起点 2020Q2 之前平均只有 1 个季度
  净值（中位数最早季度 = 2020Q1），0 只有 ≥8 季，因骨架本就由净值覆盖派生、样本起点≈基金净值起点，无样本外历史可借。
- **修复**：窗口 **12 → 8**（方案 A）。SDI 首次可用提前到 2022Q3，**覆盖 51.8% → 66.6%**，跨度 ~3.0 → ~4.3 年。
- **保留**：滚动 OLS + 曼哈顿距离是风格漂移标准算法，无需改。

### 3.2 TO_two_sided / OCI_two_sided（已统一为双边，移除单边）
- **口径**：`TO_two_sided = (total_buy + total_sell) / (2 × avg_aum)`（标准双边换手率）；
  `OCI_two_sided = (TO_two_sided − 基金内均值) / 基金内标准差`（基金内 z-score 离差）。
- **问题**：原 `TO_calc`（单边）只用了 `基金持仓变动_批量.csv` 的「本期累计买入金额」（无卖出列），
  只能算买入侧单边、系统性低估真实换手。用户拍板**统一为双边**——项目原有被误归为"无用数据"的
  `数据/无用数据/基金换手率_计算值.csv`（含 `total_buy/total_sell/avg_aum`，且
  `turnover_rate == (买+卖)/(2×净资产)` 校验最大误差≈0）已拷为 `data/L3_交易行为层/基金换手率_双边_含卖出.csv`，
  作为唯一主变量。**单边 `TO_calc`/`OCI` 已移除。**
- **avg_aum 澄清**：是**该半年区间（如 2020H2）的平均净资产（AUM，单位亿元）**，即基金总资产规模，
  **不是时点 NAV 价格、也不是持仓规模**。分母用总 AUM（非 holdings）使不同规模基金可比；除以 2 是因双边
  把同一批股份的买和卖都计了一次。
- **OCI 非冗余说明**：TO 衡量「绝对交易活跃度」（跨基金可比）；OCI 衡量「相对自身基线的偏离」
  （基金内固定效应下可比），直接服务"过度自信→比平时交易更多"的研究假设。二者互补，非冗余。
- **现状**：覆盖 33.3%（源文件为半年频 9 个快照，200 基金，2021Q1–2025Q1），缺失季度为 NaN。
  这是**数据源本身频率限制**，非拼接 bug，论文以该双边子集为分析样本并说明口径限制即可。

## 四、L4 风险管理层（风险应对）

**指标**：`ARG`（风险调整幅度，早期文档曾称"主动风险增益"/"调仓收益缺口"，构念与算法一致，见稿件 §3.5.1）、`return_volatility`（收益波动率）。

> 层内说明：原始设计（`5层架构完整研究方案`）曾拟为 L4 设第三个指标 `Δβ`（beta 变化率），最终未实现；
> 后续以日频 NAV 构造的 `idio_vol`（特质波动）与 `TM_β₂`（择时系数）曾作为 L4/L3 候选**解释**指标接受检验，
> 因同样本增量 ΔR²≈+0.002 无实质增量，**未纳入正式指标体系**，仅作探索性披露（见稿件 §4.4.11（ii））。
> 因此 L4 正式指标为 2 个。

### 4.1 ARG（无 bug）
- **口径**：`ARG = Σ_t |RG_t|`（季度内 3 个月 RG 绝对值之和）；`RG_t = R_fund,t − Σ w_i·R_i,t`
  （持仓快照个股级权重 `w_i = hold_ratio/100` × 个股季度收益 `r_i`，每只股票独立一类）。
- **问题**：无实现 bug。早期覆盖受 `个股月收益率_全量.csv` 仅 108 只限制 → 已用 AkShare 新浪源
  按持仓股全量重抓（约 4185 只成功、364100 行），**覆盖升至 99.9%**；关联 `RG` 覆盖 88.8%。
- **保留**：方法标准（个股级权重，不走行业聚合），无需改。

### 4.2 return_volatility（无 bug）
- **口径**：基金季度收益序列做**滚动 8 期（季度）样本标准差**（ddof=1，min_periods=3）。
- **问题**：无实现 bug。早期文档曾误写输入=净值历史，实际代码读 `基金季度收益.csv`，已修正文档。
- **现状**：覆盖 92.6%。

## 五、L5 认知偏差层

**指标**：`de`（处置效应）、`lsv`（交易趋同度 / 共识偏离度）、`risk_asym`（风险不对称）。

### 5.1 de（处置效应，Odean 1998 持仓快照法，保留）
- **口径**：仅 6/12 月末（半年报 / 年报）**全持仓快照**参与；相邻两期快照对比：消失股=实现卖出、
  仍在=账面持有；用个股期间收益判盈亏 → `PGR`（卖出股中赢家占比）、`PLR`（持有股中赢家占比）、
  `DE = PGR − PLR`。
- **问题**：无实现 bug。**均值 −0.12（机构"持赢售亏"的反向处置）**——与散户"处置效应"（卖赢持亏）符号相反，
  这是机构投资者的已知结果，并不"不合理"。
- **保留**：Odean 1998 是经典方法，按原则保留；覆盖 44.4%（仅 6/12 月快照约束，非 bug）。

### 5.2 lsv（交易趋同度 / 共识偏离度，LSV 1992，已对齐教科书口径）
- **口径**：`H_i = |p_i − p̄_t| − AF`；`p_i = B/(B+S)`（某股票被净买入的基金占比，LSV1992 教科书买入占比）；
  `p̄_t` = 当期所有股票 `p_i` 的横截面均值（市场整体交易方向基准）；
  `AF = √(2/π)·√(p̄_t(1−p̄_t)/n)`（零假设随机买卖下 `|p_i−p̄_t|` 的期望，扣除随机噪声）；
  基金层面 `lsv = 对各股 H_i 取均值`。
- **问题 / 修复**：
  1. **数据限制**：仓库只有「累计买入股票明细」（买入侧），无真实逐股买卖方向，故用**持仓快照增减方向**
     作买卖代理（增持基金数 B / 减持 S）——这是 LSV/Wermers 的标准做法（用季度间持仓变动定义买/卖，
     非逐笔成交），缺真实方向时可用。
  2. **代码与文稿不一致（已修）**：代码原误用带符号净比 `p_i=(B−S)/(B+S) ∈[−1,1]`，导致输出**全正**
     （均值 0.42）且测不出经典负向"反向交易"。2026-08-12 改回教科书**买入占比** `B/(B+S) ∈[0,1]`，
     使**代码 = 文稿 = LSV1992 三者一致**，并恢复负值语义。
  3. **论文命名**：文稿已将"羊群效应"改称中性"交易趋同度 / 共识偏离度"（样本整体反向交易，中性标签更贴切），
     已加构念效度说明——合理，建议保留。
- **现状**：均值 **0.089**、范围 [−0.068, 0.276]、约 0.2% 为负，量级**贴合经典 LSV 文献**（Wermers ≈ 0.02–0.07），
  覆盖 44.3%。与原面板 lsv（基于真实买卖方向、均值 −0.23）**数据源不同、不可直接比**，已在论文标注为代理口径。
- **保留**：LSV1992 有文献背书；若需严格复现原面板，需补 P2（逐股买卖方向，见下文）。

### 5.3 risk_asym（风险不对称，真 bug，已修复）
- **口径**：`σ(盈利期收益) − σ(亏损期收益)`（杠杆效应：盈利期波动 vs 亏损期波动）。
- **问题（真 bug）**：原实现按「基金全历史」取**一个常量**（同基金所有季度取值完全相同）→ 在**基金固定效应**
  面板回归中该变量基金内变异为 0、**无法识别**（直接被固定效应吸收，等于没这个变量）。
- **修复**：`calc_risk_asym(window=8, min_periods=4)` 改为**逐期滚动窗口时变量**
  （窗口内盈利期>0 收益标准差 − 亏损期≤0 收益标准差）。
- **现状**：覆盖 73.7%，**同基金内取值数中位 21**（原 1），均值 0.034，范围 [−0.126, 0.479]——
  现在在固定效应下可被识别。文献依据：杠杆效应（Black 1976 / Christie 1982 / Bekaert & Wu 2000）。
- **保留**：修复后的时变量是标准杠杆效应度量，无需改。
