Return Gap (RG) 数据源仲裁与诚实零结果报告

基金经理行为分析研究 · 数据可信度仲裁 · 生成日期 2026-08-21 · 关联脚本 _arbitrate_RG_20260821.py / _test_RG_regression_20260821.py
核心结论（一句话）： 面板既有的 RG 列（非 v2 源，358 只基金）经精确复刻验证无误；v2 持仓源（仅取 6/12 月全持仓）是其 400 只超集，二者在共同基金上仅中度相关（corr=0.427）。在 M4 同规格、项目权威口径双向聚类 (CGM2011) 下，两源 RG 对 alpha 与未来收益均不显著（|t2w|<0.1，p>0.98）。此前"RG 强显著 (t=−7.68 / −3.92)"为伪信号，已作废。RG 不构成可用的 L3 深化指标——这是一项应诚实披露的零结果。

1. 背景与授权

用户此前授权："以新增 RG_v2 列 + 重跑 M4 含 RG 的方式落入管线并刷新 v4 基准"。执行首步（向面板新增 RG_v2）时，发现候选列分布异常（std=73、max=5068、与原 RG 相关仅 0.099），经定位为 v2 持仓文件 3/9 月快照仅为前十大持仓 所致，立即回滚面板。本报告的仲裁即在此回滚前提下，彻底厘清 RG 应采用哪个数据源、是否真的不显著。

2. 方法：精确复刻原始 RG 计算

为获得可信任的对照基线，本仲裁逐行复刻 06_因变量.py::_compute_RG 的全部逻辑，不做任何简化：

  • 快照日期：rd = to_panel_date(report_date) = 报告日 +1 天；快照季度 q = rd.dt.to_period("Q")。
  • 真实基金季度：q = (report_date − 1天).dt.to_period("Q")（与 06 由净值派生的 NAV 季度一致，非 to_panel_date 后的季度）。
  • 快照选择：取最近一个 快照q ≤ 基金q 的持仓快照（半年频滞后，无前视）。
  • 归一（关键）：port = Σ wᵢ·rᵢ / Σ wᵢ(已匹配收益)，再 RG = quarter_return − port。仅对"有收益的个股"权重之和做归一。
RG = quarter_return − ( Σᵢ wᵢ·rᵢ ) / ( Σᵢ wᵢ ) , i 仅遍历"个股季度收益存在"的持仓

6. 根因：此前"强显著"为何是伪信号

2026-08-20 记录中"RG 翻盘 (t=−7.68 / −3.92 强显著)"由两个独立错误共同制造，均已定位并修正：

错误① 归一式写错本人 RG_clean 脚本误用 (qr − port)/ws（整体除以匹配权重和），而正确式应为 qr − port/wsum。当快照匹配权重和 ≈0.85 时，错误式将噪声放大约 1/0.85 倍，人为制造离散度与表面显著性。 错误② 3/9 月前十大污染v2 文件的 3/9 月快照仅为前十大持仓（权重和 0.3–0.5）。原始 _compute_RG 的"快照q ≤ 基金q"选择逻辑会把这些残缺快照选入 Q1/Q3 基金收益，再经归一放大成极端噪声（max=5068），是 t=−7.68 的主要来源。

本报告已严格采用正确归一并剔除 3/9 月、仅取 6/12 全持仓，两个伪信号来源同时消除，得到第 3–5 节的干净结论。

7. 结论与建议

  • 面板权威 RG（非 v2，358 只）维持不变，不新增 RG_v2 列；其计算已认证无误（corr=1.000）。
  • RG 不构成可用的 L3 深化指标。两源、两因变量、双向聚类下均 n.s.，与既有的"SDI 显著、TO_wind 边际"格局互补——L3 的可用信号仍来自 SDI 与 TO_wind。
  • 零结果是论文的诚实贡献："即便引入信息密度更高的季度频 Return Gap，也无法解释基金 alpha/未来收益的跨期差异" 本身支持"业绩 durable 来源在风险(L4)与认知(L5)层"的核心论点，应在报告 §6 作为负结果明确披露。
  • 若未来获得真正的季度全持仓（彻底净化 Q1/Q3 滞后），可重做 RG；但在当前数据下，切换数据源（v2）只会引入 42 只额外基金与中度分歧，且不改变"RG 不显著"的结论，故无必要。
