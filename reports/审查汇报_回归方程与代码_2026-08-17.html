3两套回归规格的明确区分（审查核心）

规格 A · M4（v4 基准，权威主回归）

研究问题：在控制 FF5 因子与全部行为/控制变量后，各行为指标对「基金选股 alpha」的联合边际贡献。

$$r^{ff5}_{it}=\alpha+\beta_1\log AUM_{it}+\sum_{f\in\{MKT,SMB,HML,RMW,CMA\}}\beta_f\,ff5_{fit}+\beta_{age}\log Age_{it}+\beta_{ten}mgr\_tenure_{it}$$ $$+\beta_{AS}AS_{it}+\beta_{ICI}ICI_{it}+\beta_{HHI}HHI_{it}+\beta_{SDI}SDI_{it}+\beta_{TO}TO^{wind}_{it}+\beta_{ARG}ARG_{it}+\beta_{RV}RV_{it}$$ $$+\beta_{de}DE_{it}+\beta_{lsv}LSV_{it}+\beta_{ra}RA_{it}+\sum_{y}\delta_y\mathbf 1[year=y]+\varepsilon_{it}$$ 因变量 ff5_adj_return_w（FF5 调整 alpha，全变量 1%/99% 缩尾）。估计量：混合 OLS，无基金 FE；仅 C(year) 吸收年份效应；SE 为 fund×year 双向聚类（CGM2011）。N=2,264 / 348 基金 / R²=0.129。
公式里的 ∑_y δ_y·1[year=y] 是什么？ 这是年份固定效应（year fixed effects）的紧凑写法。
  • 1[year=y] 是指示函数（虚拟变量 / dummy）：当观测 i 的年份等于 y 时取 1，否则取 0。
  • δ_y 是第 y 年的系数。对每一条观测，所有年份里只有"它自身那一年"对应的指示为 1，因此求和后该项坍缩为 δ_year(i)——等价于"给每个年份一个独立的截距偏移"。
  • 作用：吸收所有基金共同面对的宏观 / 市场冲击（牛熊、利率、风格轮动、系统性风险），避免把"时间趋势 / 市场 beta"误归为经理的截面或时序能力。这正是代码里 C(year)（statsmodels 自动展开为年份哑变量，见 §6 行 394）所做的事。
一句话：∑_y δ_y·1[year=y] = "一整套年份哑变量"，让模型只比较"同一年内"的基金差异。
关键结论：此规格下 SDI 近零（β=−2.3e-6, t=−0.00, p=0.999）、TO_wind 不显著（t=1.07, p=0.287）；而 ARG(t=2.98***)、risk_asym(t=3.57***)、de(t=−2.99***)、ICI(t=3.74***)、AS(t=−2.81***) 显著。L5 增量 R²=0.035。
规格 B · H1–H5（HONEST 诚实版，单指标规格）

研究问题：在吸收基金固定效应后，单个行为指标对「原始季度收益」的边际效应（避免多重共线性掩盖，逐假设检验）。

$$r^{q}_{it}=\alpha_i+\beta\cdot IV_{it}+\sum_{c\in C}\gamma_c\,C_{it}+\sum_{y}\delta_y\mathbf 1[year=y]+\varepsilon_{it},\qquad \alpha_i=\text{基金 FE（within demeaning）}$$ 因变量 quarter_return；IV ∈ {SDI, TO_wind, TO_two_sided, OCI, SDI+TO+OCI}；控制集 C = {log_aum, log_fund_age, mgr_total_tenure_v2, gender_m, cfa_d, edu_postgrad}；SE 为 fund×year 双向聚类。估计量含基金 FE demeaning。
关键结论：此规格下 SDI 显著（β=0.103, t=2.46**, H1/H5 N=6,337）、TO_wind 边际（t=1.78*, p=0.075, H2 N=8,480）；联合规格 H4（N=1,192）中 SDI 仍显著（t=3.09***）。「基金 FE」吸收了跨基金水平差异，使风格漂移对季度收益的时序内变异显著。
为何两套结论不同却都正确？规格 A 的因变量是「剔除 FF5 风格因子后的 alpha」，且未吸收基金 FE —— SDI 衡量的是风格权重时序漂移，其水平信息已部分被 FF5 因子与截距吸收，故对 alpha 的追加贡献近零；规格 B 的因变量是「原始季度收益」并吸收基金 FE，捕捉的是 SDI 对收益时序波动的边际解释力。二者回答不同问题，同时成立、互不矛盾，论文应分别陈述并明确标注规格。

③ 收益差 RG（选股贡献）

$$RG_{it}=r^{q}_{it}-\sum_{j}w_{ij}\,r_{jt}$$w_ij 为上一期持仓快照权重，r_jt 为个股季度收益；衡量「基金实际收益 − 持仓隐含收益」。

④ _ts_alpha 是什么、从哪里来？（用户追问）

来源定位：_ts_alpha 不是从 lib_metrics 或任何外部库导入的，它是 06_因变量.py 里紧挨在 _alpha_by_fund 上方、模块级的本地辅助函数（文件第 141–149 行）。整份流水线里只有这一个定义位置，回归与综述引用的 alpha 全部由它算出。
D:\Desktop\基金经理行为分析研究\指标计算流水线\06_因变量.py · _ts_alpha()（第 141–149 行）
def _ts_alpha(y, X):
    """单基金时序回归 y = a + b·X 的截距(alpha)。y,X 已按行对齐、屏蔽 NaN。"""
    y = np.asarray(y, float); X = np.asarray(X, float)
    mask = ~(np.isnan(y) | np.isnan(X).any(axis=1))   # 剔除含 NaN 的行
    if mask.sum() < X.shape[1] + 5:            # 有效样本 < 自变量数+5 → 不可估，返回 NaN
        return np.nan
    A = np.column_stack([np.ones(mask.sum()), X[mask]])  # 设计矩阵 [1, X]
    beta, *_ = np.linalg.lstsq(A, y[mask], rcond=None)  # 最小二乘解
    return beta[0]                              # 返回截距 = alpha

⑤ 逐步拆解：它到底在干什么

  • 本质：对单个 (y, X) 数据集，用 np.linalg.lstsq 直接解最小二乘问题 min‖y − [1, X]·β‖²，并返回截距项 β₀。因为这是"逐基金算一个截距"，没必要为每只基金单独调 statsmodels，手写 lstsq 更轻量、确定性强、可复现。
  • NaN 屏蔽：mask = ~(isnan(y) | isnan(X).any(axis=1)) —— FF5 因子在某些季度缺失（早期无月度因子聚合），该行会被整体剔除，避免 lstsq 因 NaN 报错或产生脏估计。
  • 最小样本保护：mask.sum() < k+5（k=5 个 FF5 因子）时直接返回 NaN。一只基金若有效季度数不足，其 alpha 记为缺失，而非给一个不可信的数——这正是 §2 表中 ff5_adj_return 覆盖 97.2%（而非 100%）的原因。
  • 返回截距 = Jensen's alpha：beta[0] 是 y = α + Σβ_f·ff5_f + ε 的 α，即该基金相对 FF5 五因子的超额收益（已剔除市场/规模/价值/盈利/投资风格后的"真选股能力"）。

⑥ 与 _alpha_by_fund 的衔接（为什么 ff5_adj_return 在同一基金内是常数）

$$\hat\alpha_i=\arg\min_{a,b}\sum_{t}\big(r^{ex}_{it}-a-\sum_f b_f\,ff5_{fit}\big)^2\quad\Rightarrow\quad ff5\_adj\_return_{it}\equiv\hat\alpha_i\ \ (\forall t)$$逐基金做时序回归得到一个 α̂ᵢ，再用 df["fund_code"].map(out) 把同一个 α̂ᵢ 广播回该基金的所有季度——所以 ff5_adj_return 在单只基金内部是常量，跨基金才变化。这正是"基金层 alpha"被用作 M4 因变量的机理。
# _alpha_by_fund 的广播逻辑（节选）
out = {}

一句话总结：_ts_alpha 是定义在 06_因变量.py 本地的"最小二乘取截距"小工具；_alpha_by_fund 用它为每只基金算出 FF5-alpha，再广播成 ff5_adj_return 列。二者同文件、相邻定义，无任何外部依赖，逻辑闭环、可复现。

L2 持仓偏离

$$AS_{it}=\frac12\sum_{j}|w^f_{ij}-w^b_j|\quad(\min 1.0),\qquad ICI_{it}=\sum_{s=1}^{31}(\tilde w_{is}-\tilde w^{mkt}_{is})^{2},\qquad HHI_{it}=\sum_{s=1}^{31}\tilde w_{is}^{2}$$注意：ICI 与 HHI 公式并不相同——上版两式都写成 Σ(ẏ_is)² 属显示错误。正确口径：HHI = Σ_s ẏ_is²（行业内赫芬达尔集中度，值大=持仓集中少数行业）；ICI = Σ_s(ẏ_is − ẏ^{mkt}_is)²（行业主动偏离，值大=相对市场基准的行业押注偏离大）。基准 ẏ^{mkt} 取各行业横截面平均权重。行业权重经「股票级持仓 → 申万31 聚合」归一化（Σ=1），消除仓位高低干扰。AS 与 ICI/HHI 符号相反属正常（见历史解读）。

L3 交易执行

$$SDI_{i,t}=\sum_{k=1}^{4}\big|\hat w^{(t)}_{k}-\hat w^{(t-1)}_{k}\big|,\quad \hat w=\text{rolling OLS}(r^{q}_{i}\sim 4\text{风格指数},\,window=8)\ \text{权重非负归一}$$
$$TO^{wind}_{it}=\frac{\max(Buy,Sell)}{avg\_aum}\ (\text{Wind 单边口径}),\quad TO^{2s}_{it}=\frac{Buy_{it}+Sell_{it}}{2\cdot AUM_{it}},\quad OCI_{it}=\frac{TO^{2s}_{it}-\bar{TO}^{2s}_i}{sd(TO^{2s}_i)}$$SDI 窗口由 12 改为 8（暖机期缩短，有效始于 2022Q2）；TO_wind 为论文主换手率（86%）。
OCI 能不能改用单边 TO（TO_wind）来算？ 可以，且在本项目里值得考虑。
  • OCI 当前定义：OCI_two_sided = (TO_two_sided − mean_i(TO_two_sided)) / sd_i(TO_two_sided)，即基金内对双边换手率做的 z 分数标准化（lib_metrics.calc_turnover_two_sided，行 392–394）。它衡量"这只基金这一期的换手率，相对它自己历史平均是高还是低"。
  • 换成单边 TO_wind 是否可行：可行。OCI 本质只是"组内 z 分数"，与输入是双边还是单边无关；z 分数会扣除均值、除以标准差，2× 的口径倍数被标准化吸收，相对高低模式不变。
  • 改用后的好处：TO_wind 覆盖 86%（394/400 基金），而当前 TO_two_sided 仅 18%（200 只）——OCI 的可用样本将从 18% 跃升到 86%；且 TO_wind 是 Wind 的原生单边口径（MAX(买,卖)/平均净资产），无需再合成双边。
  • 注意事项：① 改名以区分口径（如 OCI_wind），避免与旧 OCI_two_sided 混淆；② TO_wind 为半年频，与 TO_two_sided 同频，但量级约为双边的一半，仅影响绝对水平、不影响基金内相对排序；③ 若主回归已用 TO_wind 作换手率主变量（M4 / H2 即如此），OCI 改用 TO_wind 能保持口径一致。
建议：在需要扩充 OCI 覆盖时，优先用 TO_wind 重算 OCI（命名 OCI_wind）；旧 OCI_two_sided 保留为 200 只子集的对照。这属于口径升级，不影响 SDI / ICI 等其他指标。

6双向聚类稳健标准误（CGM2011）实现与交叉验证

两份回归脚本均采用 Cameron–Gelbach–Miller (2011) 双向聚类：在 within(基金) demeaning 后估计 fund×year 双向聚类方差。demeaning 是线性变换，不改变聚类稳健方差估计，故与「原始 FE 模型上直接双向聚类」等价。

方差公式

$$\hat V_{tw}=\hat V_1+\hat V_2-\hat V_{12},\qquad \hat V_g=(X'X)^{-1}\Big(\sum_{c\in g} g_c\,g_c'\Big)(X'X)^{-1},\quad g_c=\sum_{i\in c}X_i e_i$$V₁=fund 一维聚类，V₂=year 一维聚类，V₁₂=fund∩year 交互簇聚类（减去避免重复计数）。

核心代码（两套脚本一致）

D:\Desktop\基金经理行为分析研究\L3_L1_regressions_HONEST_2026-08-14.py · two_way_V()
def _meat(groups, X, resid):
    k = X.shape[1]; meat = np.zeros((k, k))
    for g in np.unique(groups):
        m = groups == g
        s = X[m].T @ resid[m]            # Σ_{i∈g} X_i·e_i
        meat += np.outer(s, s)
    return meat

def _oneway_V(X, resid, groups):
    XtX_inv = np.linalg.inv(X.T @ X)
    return XtX_inv @ _meat(groups, X, resid) @ XtX_inv

def two_way_V(X, resid, g1, g2):
    g12 = np.array([f"{a}|{b}" for a, b in zip(g1, g2)])   # 交互簇
    return _oneway_V(X, resid, g1) + _oneway_V(X, resid, g2) - _oneway_V(X, resid, g12)
交叉验证（决定性正确性证据）：以 _verify_cluster_crosscheck.py 将手写 CGM 与 statsmodels 原生双向聚类（cov_type="cluster", groups=2D 整数编码，use_correction=False）比对，max|Δt| = 0.00000（逐位一致）。statsmodels 默认开启小样本 G/(G−1) 修正会使 SE 放大 ~3–6%、t 偏移 ~0.19（结论不变）——本脚本关闭修正后完全吻合，证明手写算法正确。
注：linearmodels.PanelOLS 双向 FE+双向聚类在本机 numpy 2.x 下返回 NaN，已弃用；statsmodels 原生双向聚类作为金标准。

def fe_report(df, dv, ivs, label, by="fund_code"):
    need = [dv] + ivs + [by, "year"]
    sub = df[[c for c in need if c in df.columns]].dropna(
        subset=[dv] + ivs).copy().reset_index(drop=True)
    if len(sub) < len(ivs) * 20:               # 样本量守卫：过小则跳过
        return None
    yr = pd.get_dummies(sub["year"], prefix="yr", drop_first=True).astype(float)
    sub = pd.concat([sub, yr], axis=1)
    all_x = ivs + list(yr.columns)
    g = sub.groupby(by)
    Xdm = sub[all_x] - g[all_x].transform("mean")   # ← within：每变量减基金内均值
    ydm = (sub[dv] - g[dv].transform("mean")).values   # ← DV 同样 demeaning
    X = Xdm[all_x].values.astype(float)
    y = ydm.astype(float)
    # ---- 3) 最小二乘拟合 + 残差 ----
    beta, *_ = np.linalg.lstsq(X, y, rcond=None)        # 组内回归系数
    resid = y - X @ beta
    # ---- 4) 双向聚类 SE（复用 §6 的 two_way_V） ----
    V  = two_way_V(X, resid, sub[by].values.astype(str),
                   sub["year"].values.astype(str))
    se = np.sqrt(np.maximum(np.diag(V), 0))
    tvals = beta / se
    pvals = 2.0 * _tstats.t.sf(np.abs(tvals), df=len(y) - X.shape[1])
    # ---- 5) 单维基金聚类对照（CGM one-way，早期 statsmodels 口径） ----
    V1 = _oneway_V(X, resid, sub[by].values.astype(str))
    se1 = np.sqrt(np.maximum(np.diag(V1), 0)); tvals1 = beta / se1

③ 两套规格的「计算」有什么区别、又在哪里汇合

区别（建模选择）：M4 用 statsmodels.ols 直接拟合「含 FF5 因子 + C(year) 的混合 OLS」做初估，再用手写 two_way_V 覆盖 SE；H1–H5 先做基金 FE within-demeaning（逐基金减均值，等价于吸收基金固定效应），再用 np.linalg.lstsq 做组内回归。
汇合点（方差口径）：两者最终都调用同一个 two_way_V(X, resid, fund, year)（§6 的 CGM2011 双向聚类）来算 SE 与 t —— 这正是两套规格的 SE 都经 statsmodels 金标准交叉验证、且 max|Δt|=0 的原因。
一句话：差异只在「是否 demeaning 基金 FE / 用什么拟合器」，方差估计器是同一份手写 CGM2011；因此 §3 的口径差异是研究问题差异，不是计算实现差异。

  • Wind 持仓仅前十大 → 全持仓校验不可行；DE/LSV/ARG 结构性受限于持仓源，须披露为方法局限。
